# High-Resolution Swimlane Diagrams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate the approved platform overview and 17 specialized Chinese swimlane diagrams as individually editable SVG files and 4800×2700 PNG images.

**Architecture:** Keep diagram content in a declarative JavaScript data module, compute lane/node/connector geometry in a deterministic renderer, and rasterize SVG with Sharp. Tests validate the approved diagram inventory, semantic completeness, generated SVG structure, image dimensions, and absence of undefined or clipped content.

**Tech Stack:** Node.js ESM, `node:test`, SVG, Sharp 0.34, Markdown.

---

Implement these exports:

```js
export const CANVAS = { width: 4800, height: 2700 };
export function layoutDiagram(diagram) {
  const contentLeft = 760;
  const contentRight = 90;
  const contentTop = 430;
  const contentBottom = 430;
  const laneHeight = (CANVAS.height - contentTop - contentBottom) / diagram.lanes.length;
  const phaseWidth = (CANVAS.width - contentLeft - contentRight) / diagram.phases.length;
  const nodeWidth = Math.min(560, phaseWidth - 100);
  const nodeHeight = Math.min(210, laneHeight - 70);
  const nodes = diagram.nodes.map((node) => {
    const laneIndex = diagram.lanes.findIndex((lane) => lane.id === node.lane);
    const phaseIndex = diagram.phases.findIndex((phase) => phase.id === node.phase);
    const laneTop = contentTop + laneIndex * laneHeight;
    const laneBottom = laneTop + laneHeight;
    return {
      ...node,
      x: contentLeft + phaseIndex * phaseWidth + 50 + node.order * 34,
      y: laneTop + (laneHeight - nodeHeight) / 2,
      width: nodeWidth,
      height: nodeHeight,
      laneTop,
      laneBottom,
    };
  });
  return { ...CANVAS, contentLeft, contentTop, laneHeight, phaseWidth, nodes };
}

export function renderSvg(diagram) {
  const layout = layoutDiagram(diagram);
  const nodeMarkup = layout.nodes.map((node) =>
    `<g data-node="${node.id}"><rect x="${node.x}" y="${node.y}" width="${node.width}" height="${node.height}" rx="28"/><text x="${node.x + node.width / 2}" y="${node.y + node.height / 2}">${node.label}</text></g>`,
  ).join('');
  return `<svg xmlns="http://www.w3.org/2000/svg" width="${layout.width}" height="${layout.height}" viewBox="0 0 ${layout.width} ${layout.height}"><defs><marker id="arrow" markerWidth="12" markerHeight="12" refX="10" refY="6" orient="auto"><path d="M0,0 L12,6 L0,12 z"/></marker></defs>${nodeMarkup}</svg>`;
}

export async function generateAll({ outputRoot }) {
  const manifest = [];
  for (const diagram of diagrams) {
    const svg = renderSvg(diagram);
    const svgPath = join(outputRoot, 'svg', `${diagram.id}-${diagram.slug}.svg`);
    const pngPath = join(outputRoot, 'png', `${diagram.id}-${diagram.slug}.png`);
    await writeFile(svgPath, svg);
    await sharp(Buffer.from(svg)).png({ compressionLevel: 9, adaptiveFiltering: true }).toFile(pngPath);
    manifest.push({ id: diagram.id, svg: svgPath, png: pngPath, ...CANVAS });
  }
  await writeFile(join(outputRoot, 'manifest.json'), `${JSON.stringify({ diagrams: manifest }, null, 2)}\n`);
  return manifest;
}
```

The renderer must include:

- white-to-ice-blue background, navy title bar, board and diagram ID labels;
- fixed lane header column, alternating lane fills, phase header row;
- rounded action nodes, diamonds for decisions, document nodes for artifacts, red exception nodes;
- orthogonal connectors with arrow markers and compact edge labels;
- bottom legend, key artifacts, systems, and connection-point footer;
- XML escaping and Chinese line wrapping by character count;
- unique SVG IDs per diagram and no embedded external resources.
