## 一、供应商多轮报价（:3004）

**账号**: `四川水发建设有限公司` / `supplier@2026`

### 1.1 进入多轮报价页面

1. 登录 → 投标进展 → 点击 `2026年度智慧水利大数据平台建设项目`
2. 项目详情页应显示「多轮报价」按钮（仅谈判采购项目可见）
3. 点击进入多轮报价页

**✅ 验收**: 按钮出现 = Bug#2 修复

### 1.2 报价提交（含确认弹窗）

4. R5（当前 open 轮次）输入报价金额
5. 尝试输入 `0` → 应被阻止（最小 0.01）**← M5**
6. 输入 `920000` → 点击「提交密封报价」
7. 确认弹窗显示 `¥920,000.00` + "提交后不可修改" **← 确认弹窗**
8. 点击「再检查一下」→ 弹窗关闭，未提交
9. 再次点击「提交密封报价」→ 点击「确认提交」
10. 提交后显示绿色提示「已提交报价：¥920,000.00 · 已锁定·不可修改」
11. 报价输入框消失，替换为锁定状态

**✅ 验收**: 弹窗 + 锁定 + 不可修改

### 1.3 重复提交拦截

12. 刷新页面 → R5 显示「已锁定·不可修改」，无输入框

**✅ 验收**: 严格一报制（C4）

### 1.4 排名表 + 格式 + 脱敏

13. 查看 R1/R2/R3 已公布轮次排名表
14. 价格显示 2 位小数（如 `980,000.00`）**← L3**
15. 本企业行蓝色高亮，显示「本企业」
16. 竞争对手显示「其他供应商」（非公司名）**← M1**

**✅ 验收**: 格式统一 + 脱敏

### 1.5 截止倒计时（M4）

17. 找一个 deadline 即将到期的轮次（或手动改 DB deadline 为 1 分钟后）
18. 等待过期 → 提交按钮应变为 disabled

**✅ 验收**: 倒计时禁用

## 五、API 级验证（curl）

### 5.1 C4 — 重复提交

```bash
COOKIE=<供应商登录cookie>
curl -X POST http://localhost:4001/api/supplier-portal/projects/<pid>/rounds/<rid>/quote \
  -H "Cookie: token_supplier=$COOKIE" -H 'X-Portal: supplier' \
  -H 'Content-Type: application/json' \
  -d '{"bidSupplierId":"<bsid>","quotePrice":999}'
# 应返回 400 ALREADY_QUOTED
```

### 5.2 H5 — 阶段守卫

```bash
HOST_COOKIE=<主持人登录cookie>
curl -X POST http://localhost:4001/api/bid/projects/<EVALUATING项目pid>/rounds \
  -H "Cookie: token_web=$HOST_COOKIE" -H 'X-Portal: web' \
  -H 'Content-Type: application/json' \
  -d '{"roundType":"negotiation"}'
# 应返回 409 STAGE_NOT_OPENING
```

### 5.3 H1 — 角色隔离

```bash
SUPPLIER_COOKIE=<供应商登录cookie>
curl http://localhost:4001/api/bid/projects/<pid>/rounds/<rid>/quotes \
  -H "Cookie: token_web=$SUPPLIER_COOKIE" -H 'X-Portal: web'
# 供应商角色应看不到未公布轮次的报价
```

### 5.4 M1 — UUID 脱敏

```bash
COOKIE=<供应商登录cookie>
curl http://localhost:4001/api/supplier-portal/projects/<pid>/rounds/<published_rid>/quotes \
  -H "Cookie: token_supplier=$COOKIE" -H 'X-Portal: supplier'
# 非 self 的 bidSupplierId 应为 competitor_1, competitor_2 等
```
