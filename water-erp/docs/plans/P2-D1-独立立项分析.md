### 1.2 🔴 致命 Bug：基本报价流程不可用

#### Bug #1（致命）：`myBidSupplierId` 永远为空 → 报价提交静默失败

**位置：** `RoundQuote.vue:35-38`

```ts
const projRes = await bidApi.getProject(projectId)
const suppliers = (projRes.data as any)?.suppliers ?? []  // ← 双重错误
const mySupplier = suppliers[0]
if (mySupplier) myBidSupplierId.value = mySupplier.id
```

**根因 A（后端）：** `supplier-portal.service.ts:551-601` 的 `getBidProject` 方法 Prisma `select` 不含 `suppliers` 字段——只有 `_count: { select: { suppliers: true } }`。响应永不含 `suppliers` 数组。

**根因 B（前端）：** axios 响应拦截器（`supplier-portal/src/api/index.ts:15`）已做 `response.data` 解包。`projRes` 已经是 `projectObject`，`projRes.data` = `projectObject.data` = `undefined`。即使后端返回了 suppliers，前端也会取错位置。

**后果：** `myBidSupplierId.value` 恒为 `''`（falsy）。`handleSubmit` L57 的守卫 `if (!myBidSupplierId.value)` → 静默返回。用户在 `el-input-number` 输入价格、点击「提交密封报价」→ **零网络请求、零错误提示、什么都不会发生。**

**修复方案：**
- 后端新增端点 `GET /supplier-portal/projects/:projectId/my-bid-supplier`，根据当前登录供应商 + projectId 查 `BidSupplier` 表返回 `{ id }`
- 前端改为调用该端点 + 修正 `projRes.data` → `projRes`

#### Bug #2（致命）：「多轮报价」按钮永不渲染

**位置：** `BidDetail.vue:145` + `supplier-portal.service.ts:552-577`

```html
<el-button v-if="project.roundMode" …>多轮报价</el-button>
```

`v-if="project.roundMode"` 但后端 `getBidProject` 的 Prisma `select` **不含 `roundMode`**。因此 `project.roundMode` 恒为 `undefined`（falsy），按钮永不渲染。

**后果：** 除非用户手动在地址栏输入 `/bids/:id/round-quote`，否则**完全无法进入多轮报价页面**。

**修复方案：** `supplier-portal.service.ts` 的 `getBidProject` select 块加 `roundMode: true`

### 1.3 🟡 中等 Bug

#### Bug #3：`getRoundQuotes` 拒绝 `closed` 状态

**位置：** `supplier-portal.controller.ts:458`

```ts
if (round.status !== 'published') return [];  // ← 拒绝 'closed'
```

前端 `RoundQuote.vue:42` 正确请求 `published` 和 `closed` 两种状态的报价，但后端只放行 `published`。轮次从 `published` → `closed` 后，供应商端排名表消失。

**修复方案：** 改为 `if (round.status !== 'published' && round.status !== 'closed') return []`

#### Bug #4：`listRounds` 无授权校验

**位置：** `supplier-portal.controller.ts:423-429`

```ts
@Get('projects/:projectId/rounds')
async listProjectRounds(@Param('projectId') projectId: string) {
  return this.prisma.bidRound.findMany({ where: { projectId }, ... });
}
```

无 `@Req()` 提取当前用户、无项目成员校验。任何已登录供应商可查看任意项目的轮次列表。

**修复方案：** 加 `@Req()` + `getSupplierId()` + 查 `BidSupplier` 表校验项目成员身份

### 1.4 🟢 低优先级

#### Bug #5：`submitQuote` 无 deadline 过期校验

**位置：** `supplier-portal.controller.ts:444`

后端校验了 round 存在、属于该项目、状态为 `open`，但未校验 `round.deadline` 是否已过期。过期的 `open` 轮次仍可提交报价。

**修复方案：** 加 `if (round.deadline && new Date(round.deadline) < new Date()) throw new BadRequestException('报价已截止')`

#### Bug #6：已提交报价无 UI 反馈

**位置：** `RoundQuote.vue`

`handleSubmit` 成功后按钮仍显示「提交密封报价」——无「已提交，点击修改」提示。后端是 upsert，可重复提交覆盖，但 UI 未区分「首次提交」和「修改报价」。
