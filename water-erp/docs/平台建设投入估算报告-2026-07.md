## 二、工作量估算（交叉验证三种方法）

### 方法一：代码行数法

```
22.7 万行 ÷ 15 LOC/人天（企业级 TypeScript 全栈生产率，含设计/测试/调试）
= 15,133 人天 ÷ 21.75 天/月
≈ 696 人月（含全部生命周期工作）
```

扣除基础设施代码（迁移 SQL、Prisma schema 生成部分）后，纯应用代码约 20 万行：

```
200,000 ÷ 18 LOC/人天（仅应用逻辑，架构/测试/文档单独算）
≈ 511 人月（纯开发）
+ 架构设计 15 PM + 需求分析 20 PM + 测试 40 PM + DevOps 15 PM + 文档 10 PM
≈ 611 人月
```

### 方法二：功能点法（FPA / IFPUG）

| 功能点类型 | 数量 | 复杂度 | FP 估算 |
|-----------|------|--------|---------|
| ILF（内部逻辑文件 = 数据模型） | 103 | 中-高 | ~820 |
| EIF（外部接口文件 = 集成） | 10 | 中 | ~100 |
| EI（外部输入 = POST/PUT/PATCH） | 270 | 中 | ~1,080 |
| EO（外部输出 = GET） | 242 | 中-低 | ~1,210 |
| EQ（外部查询 = 复杂列表/报表） | ~50 | 中 | ~250 |
| **合计未调整功能点** | | | **~3,460** |
| 调整因子（分布式处理、性能、复用、易安装） | | 0.85 | |
| **调整后功能点** | | | **~2,940 FP** |

生产率基准（企业级 Web 应用，国内中等成熟度团队）：**10-15 FP/人月**

```
2,940 ÷ 12 FP/人月 ≈ 245 人月（中位）
```

### 关键假设与风险

1. **团队属地**：按成都 B 类城市 CSBMK 人月基准（2.61 万元/人月）测算。若团队在一线城市（北京/上海/深圳，3.19 万元/人月），人力成本上浮约 **22%**，最终总额增至 **~1,600 万元**。
2. **需求变更**：ERP 类项目需求变更率通常 15-25%，预备金已覆盖合理的变更范围。
3. **技术栈熟练度**：假设团队对 NestJS + Next.js + Prisma + Vue 3 技术栈有一定经验；若需学习爬坡，增加 10-15%。
4. **安全合规**：等保三级 + 渗透测试 + 信创适配的详细测算见第八章，中位合计约 200 万元。信创若采用渐进策略可分摊、初期减负 40-50 万。
5. **本估算假设从零自研**。实际中，存在基于开源框架（如 JeecgBoot/RuoYi）或低代码平台的加速方案，可在 30-50% 成本下实现 70-80% 功能。
