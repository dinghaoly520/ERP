# 招投开评标业务流程说明

## 一、整体流程概览

一个招标项目从开始到结束，要经历 **5 个环节**，按顺序推进：

```
① 文件下载 → ② 加密投递 → ③ 在线开标 → ④ 专家评标 → ⑤ 资料归档
```

每个环节完成后才能进入下一个，不能跳过或倒退。

---

## 二、各环节具体做什么

### ① 文件下载阶段

**谁在操作：采购方 + 供应商**

- 采购方发布招标项目，上传招标文件（图纸、技术规范、合同条款等）
- 供应商在平台上浏览招标项目，下载招标文件回去研究
- 部分文件可能需要供应商付费后才能下载

---

### ② 加密投递阶段

**谁在操作：供应商**

- 采购方打开发标通道，供应商开始投标
- 供应商在系统中填写报价、工期承诺，上传技术方案、商务资质等文件
- **所有投标文件加密存储**，任何人都看不到内容，包括采购方
- 投标截止时间一到，通道自动关闭

---

### ③ 在线开标阶段

**谁在操作：开标主持人 + 供应商确认 + 监督人员旁站**

这是整个过程最关键、互动最密集的环节：

**开标大厅（主持人操作）：**
- 主持人设定解密时间窗口，时间一到，系统逐家解密供应商的投标文件
- 解密成功后，系统自动校验文件是否完整、没有被篡改
- 主持人将每家供应商的报价、工期承诺、质量目标等关键信息录入系统（这个过程叫"唱标"）

**供应商确认：**
- 每家供应商在自己的门户上查看唱标信息是否与自己提交的一致
- 一致就点"确认"，发现不对可以提出异议

**监督端：**
- 监督人员实时查看开标过程中的每一个操作记录
- 发现异常可以标记、升级，但不能干预实际操作
- 所有操作自动生成日志，事后可追溯

---

### ④ 专家评标阶段

**谁在操作：评标专家 + 采购方管理**

开标完成后，进入专家评标环节。每位专家在专家门户上按照 **5 个步骤** 依次完成：

| 步骤 | 做什么 | 说明 |
|------|--------|------|
| **第1步：身份核验** | 手机验证码确认身份，签署保密协议和纪律承诺 | 确保是专家本人操作 |
| **第2步：标书获取** | 下载各供应商的投标文件 | 此时文件已解密，专家可以查看 |
| **第3步：辅助评标** | 查看 AI 给出的风险提示和合规分析 | 辅助参考，不替代专家判断 |
| **第4步：独立打分** | 从资格、符合性、商务、技术、价格 5 个维度逐项打分 | 各专家独立操作，互不可见 |
| **第5步：确认报告** | 查看系统生成的评审报告，确认无误后提交 | 全部专家确认后生成最终排名 |

**采购方管理端：**
- 实时查看各专家的打分进度（谁打完了、谁还在打）
- 全部完成后，一键生成评标结果排名

---

### ⑤ 资料归档阶段

**谁在操作：采购方**

- 系统自动收集整理全部过程资料，生成 **7 类归档文件**：
  1. 招标项目基本信息
  2. 投标供应商名单
  3. 开标记录表
  4. 供应商确认与异议记录
  5. 专家评分明细
  6. 评标结果汇总
  7. 监督日志
- 所有文件附带防伪校验码，确保归档后不会被篡改

---

## 三、贯穿全程的辅助功能

### 澄清答疑

- 在投标准备和评标过程中，供应商如果对招标文件有疑问，可以在线提交澄清请求
- 采购方在线回复，所有问答记录留痕

### 全程监督

- 从开标到评标结束，监督人员可以全程查看操作日志
- 发现问题随时标注，但不能直接修改任何数据
- 相当于全程"摄像头"，保证过程透明可追溯

---

## 四、各角色职责一览

| 角色 | 负责什么 |
|------|----------|
| **采购方/开标主持人** | 发布项目、组织开标、录入唱标信息、处理异议、启动评标、生成结果、归档 |
| **供应商** | 下载招标文件、编制投标文件、加密提交、开标后确认唱标信息 |
| **评标专家** | 身份确认、签署承诺、查看标书、参考AI分析、独立打分、确认评审报告 |
| **监督人员** | 实时查看操作日志、标记异常、导出监督记录（只看不操作） |

---

## 五、几个关键保障措施

- **投标文件加密**：供应商提交的文件全程加密，开标前谁也看不到
- **文件防篡改**：每份文件都有数字指纹，解密时自动校验
- **解密时间窗口**：只能在规定时间内解密，防止提前或延后操作
- **专家独立打分**：各专家之间看不到彼此的分数，保证独立性
- **操作全程留痕**：谁在什么时间做了什么操作，全部自动记录
- **归档防伪链**：归档文件环环相扣，事后任何修改都能被发现
