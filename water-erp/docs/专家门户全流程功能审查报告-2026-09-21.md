## 二、缺陷清单

### P2-1 报告确认后「确认评审报告」按钮不消失（服务端 canConfirm 永真）

- **现象**：`reportConfirmed=t`（DB 已确认、状态板 1/5）后，重新加载页面「确认评审报告」按钮仍然可点，无任何已确认/已锁定标识。再次点击会重复确认（服务端幂等，无数据损害，但严重误导专家）。
- **根因**（三处叠加）：
  1. `apps/api/src/expert/expert.service.ts:2116` — `canConfirm: expert.progress >= 100 && allVerified` **漏了 `!expert.reportConfirmed`**，确认后接口永远回 `canConfirm:true`（已实测复现）。
  2. `ReportStep` 组件没有"已确认"态渲染（未接收 `reportConfirmed` prop，无徽标/锁定文案）。
  3. `handleConfirmReport`（evaluate 页 L902）确认成功后只 `loadProject()` 不 `loadReport()`。
- **建议修复**：服务端补 `!expert.reportConfirmed`；前端 ReportStep 增加已确认态（隐藏按钮 + 成功徽标），确认成功后同时刷新 report。

### P2-2 个人资料「空姓名」保存假成功 + 邮箱错误提示笼统

- **现象**：编辑资料把姓名清空后点保存 → toast「资料已更新」，但 DB 中 displayName 未变（仍为原值）。输入非法邮箱保存 → toast 只显示笼统「更新失败」（服务端 400 的 `email must be an email` 未透出）。
- **根因**：`apps/api/src/expert/expert.service.ts:126` — `if (dto.displayName) data.displayName = dto.displayName;` 空字符串为假值被静默跳过，但接口返回 200 成功。DTO（`update-profile.dto.ts`）对 displayName 无 `@IsNotEmpty()`/长度约束；前端也无必填拦截。
- **建议修复**：DTO 加 `@IsNotEmpty({ message: '姓名不能为空' })`（或前端禁用保存）；toast 透传服务端校验消息。

### P2-3 /tasks 空态文案指向不存在的按钮；英雄项目无组长导致动议/异议/末签无入口

- **现象**：「评审待办」页空态文案写着「点击『发起动议』按钮新建」「点击『提交异议』按钮新建」，但页面上**没有任何按钮**——这两个按钮仅组长（`isLeadAnywhere`）可见（tasks/page.tsx:217/356）。非组长专家看到的是永远无法兑现的操作指引。
- **连带数据缺口**：英雄项目 5 名专家 `isLead` 全部为 false → 本项目内「发起动议」「提交异议」「组长末签（C2）」三个功能均无入口，评标结果生成的末签前提无法满足。
- **建议**：①空态文案按角色分流（非组长显示"动议由评审组长发起"）；②演示数据为一名专家补 `isLead=true`（:3007 或种子）。

### P3-1 开标消息弹窗 Esc 关闭承诺失实

弹窗文案「按 Esc 或点击遮罩关闭」，但全代码无 Escape keydown 处理器（evaluate 页与 hall-message-panel 均无）——实测 Esc 不关闭，只有 X 按钮与遮罩可关。建议补 Esc 监听或改文案。

### P3-2 异常供应商的评分输入仍可编辑

四川省通信产业（解密异常）在打分步：提交按钮正确禁用 + 警示横幅正确显示，但滑块/数值输入/通过-不通过按钮**仍可交互**，专家可能白填一通后才发现无法提交。建议对不可评供应商整卡置灰（`pointer-events-none`）。

### P3-3 roomCodeAt 为空时口令闸死锁（加固建议）

`expert-room.util.ts:84` 要求 `roomVerifiedAt >= roomCodeAt` 才算已验。若出现 `roomCode` 非空而 `roomCodeAt` 为 NULL 的数据（手工改库/数据漂移——正式流 :3007 设置口令时两列同写，不会发生），则专家**验证成功也无法解锁**，且页面一直提示"请先输入口令"（验证又明明成功了），形成误导性死循环。建议 null 时回退 `updatedAt` 或视为已满足。

### P3-4 未签到时 my-scores 403 控制台噪音

进入向导但未签到时 `GET /expert/projects/:id/my-scores` 返回 403（设计内"optional—ignore"），页面静默吞掉但控制台留红。低危；可改 204 或前端跳过请求。
