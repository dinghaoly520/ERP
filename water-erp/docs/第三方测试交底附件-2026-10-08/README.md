# 第三方测试交底附件使用说明

日期：2026-10-08。对应主文：`../第三方测试交底-技术栈与功能清单-2026-10-08-代码核验版.md`。

清单描述2026-10-08工作区中的接口、数据模型、路由、依赖及功能。代码版本为 `f65e82acbb7d040d2f1d902087a1bd5f5cefffe9`，含工作区未提交修改。附件不包含运行测试结果。

| 文件 | 内容 | 使用方式 |
|---|---|---|
| `01-API接口清单.csv` | 59 个控制器文件中的 898 个 HTTP 路由声明，含方法、路径、Swagger摘要、类/方法鉴权注解、源码位置 | 用于接口覆盖矩阵；接口权限由全局守卫、服务层及数据归属校验共同控制 |
| `02-数据库模型清单.csv` | 157 个 Prisma 模型、实际表名映射、模型约束 | 用于数据库范围与核心实体核查；模型数不等于运行库物理表数，分区/迁移表/向量库另计 |
| `03-数据库字段清单.csv` | 2,307 个 Prisma 字段声明，含关系字段、类型、属性和注释 | 关系字段和物理列分别记录；`@@map`/`@map`定义名称映射，迁移SQL定义结构变更 |
| `04-数据库枚举清单.csv` | 31 个 schema 枚举的全部取值 | 部分业务状态用String/Json存储，由服务代码定义，不在schema枚举范围内 |
| `05-前端路由清单.csv` | 8 个活跃前端的 111 个 page.tsx 声明和 2 个 route.ts Handler | 路由组已去掉；含兼容重定向与无菜单入口页面，不等于 113 个独立功能页 |
| `06-依赖版本清单.csv` | 252条直接依赖声明：241条JS/TS生态依赖和11条OCR requirements条目 | 含同一依赖在不同应用的重复声明，不等于252个不同软件；保留声明/锁版/未锁版及开发依赖差别，未展开所有传递依赖 |
| `07-功能点测试矩阵.csv` | 147个功能组：前端91组、后台56组 | 与主文编号对应，前后台有跨层对应；测试状态统一“未执行”，供测试团队填结果/缺陷号 |
| `代码清单快照.json` | 数量统计和被扫描源文件的 SHA-256 | 用于发现扫描后源码漂移；不是全部仓库文件或完整交付包的签名 |
| `generate-dependency-inventory.py` | 依赖声明及lock版本提取器（Python3 + PyYAML） | 不读取.env、不联网、不检查实际运行时使用 |
| `generate-function-matrix.py` | 从主文抽取功能组（Python3标准库） | 主文变化后重新生成矩阵 |
| `generate-code-inventory.cjs` | 可重复执行的清单生成器 | 在安装仓库依赖后，从 `water-erp/` 执行下方命令 |

```bash
node docs/第三方测试交底附件-2026-10-08/generate-code-inventory.cjs
python3 docs/第三方测试交底附件-2026-10-08/generate-dependency-inventory.py
python3 docs/第三方测试交底附件-2026-10-08/generate-function-matrix.py
```

CSV 为 UTF-8 BOM 编码，可直接用 Excel/WPS 打开。生成器采用 TypeScript AST 提取控制器路由；不包括 Socket.IO 事件、OCR/U盾独立服务接口，后两者见主文。接口计数不是业务功能点数量，也不是经 HTTP 实测的可用端点数量。运行环境的Swagger/OpenAPI提供部署后的接口描述。

功能矩阵包含功能编号、描述、前置条件、实现位置、测试状态和缺陷编号。附件不包含账号口令、个人身份证信息、私钥或数据库连接密钥。
