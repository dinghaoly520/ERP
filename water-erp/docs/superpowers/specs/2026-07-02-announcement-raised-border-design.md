# 公告区域组件边框凸起设计

**日期**：2026-07-02  
**范围**：`apps/public-portal`（3002 信息门户首页）  
**目标**：为首页公告区域各组件增加新拟态（Neumorphism）边框凸起效果，基于页面背景色配色

---

## 背景

3002 首页公告区域当前采用玻璃拟态（glass morphism）风格——半透明背景 + backdrop-filter 模糊 + 浅色边框。整体视觉偏"平"，公告内容与周边区域的视觉层次不够分明。需要为公告组件增加"浮出页面"的立体凸起感，引导用户注意力。

## 设计目标

1. 公告区域 4 类组件全部增加边框凸起效果
2. 阴影配色以页面背景色 `oklch(0.975 0.012 258)` 为基准推导
3. 与现有玻璃拟态风格兼容，不破坏现有圆角/流光边框/悬停动画
4. 维持 reduced-motion 媒体查询下的无障碍处理

## 色值体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 页面背景 | `oklch(0.975 0.012 258)` | `--bg` 变量，阴影色推导基准 |
| 亮高光 | `oklch(1 0 0 / 0.85)` | 顶/左侧高光，模拟光源照射 |
| 暗投影（默认） | `oklch(0.55 0.03 258 / 0.15)` | 底/右侧投影，形成"浮起"纵深 |
| 暗投影（悬停） | `oklch(0.45 0.08 258 / 0.12)` | 悬停时远投影，卡片进一步抬升 |
| 内高光线 | `inset 0 1px 0 oklch(1 0 0 / 0.7)` | 各组件顶部边缘浮起感 |

核心阴影公式：
```css
/* 外凸 */
box-shadow:
  2px 2px 5px oklch(0.55 0.03 258 / 0.15),
  -2px -2px 5px oklch(1 0 0 / 0.9);

/* 内凹（仅 tabs 激活态） */
box-shadow:
  inset 2px 2px 5px oklch(0.55 0.03 258 / 0.15),
  inset -2px -2px 5px oklch(1 0 0 / 0.7);
```

## 各组件设计

### ① 公告分类 Tab 按钮（`.announce-tab`）

| 状态 | 效果 |
|------|------|
| 默认 | subtle 外凸 shadow + 背景微提亮为 `#f8faff` |
| 悬停 | `translateY(-1px)` + 投影加深 |
| 激活 `.is-active` | 内凹 inset shadow（暗示"被按下"），保持 `scale(1.02)` |

### ② 精选公告大卡片（`.announce-featured`）

| 状态 | 效果 |
|------|------|
| 默认 | 外层容器外凸方向性双影 + `.announce-featured-inner` 内高光线 |
| 悬停 | `translateY(-4px)` 保留，投影过渡到更强方向投影 |

### ③ 最新公告侧边列表（`.announce-side`）

| 状态 | 效果 |
|------|------|
| 默认 | 整体容器外凸 shadow + 内高光线 |
| 悬停容器 | 边框加深 + 投影增强（保持现有行为） |
| 悬停列表项 `.announce-side-item` | `translateY(-1px)` + 浅方向投影 |
| 序号图标悬停 | 保持现有立体渐变 + scale 增强 |

### ④ "全部公告"链接按钮（`.announce-view-all`）

| 状态 | 效果 |
|------|------|
| 默认 | subtle 外凸 shadow + 内高光线，背景稍亮 |
| 悬停 | 投影加深 + 箭头右移（保持现有效果） |

## 实施计划

- **修改文件**：`apps/public-portal/src/app/globals.css`（约 80 行公告相关 CSS）
- **不修改**：`home-client.tsx`（JSX 结构不变，完全靠 CSS 实现）
- **测试方式**：启动 `pnpm dev:public`，浏览器访问 `localhost:3002`，视觉验证公告区域凸起效果
- **风险**：低——仅 CSS 修改，不改动 JSX/DOM 结构

## 无障碍与兼容性

- `box-shadow` 纯装饰性，不影响屏幕阅读器
- `@media (prefers-reduced-motion: reduce)` 下禁用所有过渡动画（已有）
- 阴影为 CSS 标准属性，兼容所有现代浏览器
