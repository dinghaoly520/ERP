# :3011 移动驾驶舱「一屏总览」信息架构改造设计

日期：2026-11-17 ｜ 状态：已与用户逐节确认（范围=仅 :3011；形态=一屏总览+下钻；数据库=方案 A；台账=默认 5 条+展开更多）

## 1. 问题（量化实录，390×844 视口实测）

| Tab | 页高 | 折合屏数 | 成因 |
|---|---|---|---|
| 数据库 | 3501px | **4.1 屏** | 12+ 张卡片纵向堆叠（节资排行 523px、供应商动态 492px、质效 277px…） |
| 台账 | 2550px | **3.0 屏** | `PAGE_SIZE=15` 全量直出 + IntersectionObserver 触底自动追加 |
| 进展 | 1222px | 1.4 屏 | 达标，不动 |

用户裁定：每个模块都做成长滚动页不合理，采用「一屏总览 + 下钻」重构。

## 2. 目标 / 非目标

**目标**
- 数据库页、台账页首屏即全貌（核心信息 + 下钻入口），页高显著收短（数据库 ≤1.5 屏、台账首屏 ≤1.5 屏）。
- 下钻内容**原样复用现有卡片组件**——纯前端重组，零 API / 数据口径 / 后端改动。

**非目标**
- 进展页（1.4 屏）、水叮当对话页（天然滚动）不动。
- 不改下拉刷新、filter-store 记忆、指标卡环比、今日要报指纹缓存（2026-11-16 修复）。

## 3. 数据库页改造（`apps/mobile-portal/src/app/(main)/dashboard/page.tsx`）

### 3.1 首屏（保留项，顺序不变）

1. 今日要报卡（178px）
2. 区间/公司控制行
3. 指标卡 grid（现有 6 张 MetricCard：总数/异常/总预算/已成交预算/成交总额/累计节资，含环比与下钻跳转）
4. 采购执行趋势 SectionCard（253px，含按压高亮/当日弹层，行为不变）
5. AI 综合分析入口（现有折叠态，116px）

### 3.2 「分析中心」宫格（新增，替代其余卡片直出）

3 列宫格（grid-cols-3，第二行 2 格居左），tile = cgzxui 图标井 + 标题（lucide 图标，m-rise 阶梯入场）。5 个分组与现有卡片的映射：

| 宫格 | 图标建议 | 收纳的现有 SectionCard |
|---|---|---|
| 排行榜 | Trophy | 公司龙虎榜、节资率项目排行 Top5 |
| 构成分析 | PieChart | 采购方式分布、项目规模分析、结果构成、未成交原因分析 |
| 公司对比 | Building2 | 各公司采购分布、项目质效 |
| 风险告警 | AlertCircle | 风险项目预警、资源告警 |
| 供应商动态 | Users | 重点供应商动态 |

点击 tile → `BottomSheet`（标题=宫格名）承载该组全部 SectionCard（卡片 JSX 原样搬移，卡片自身的下钻弹层保持——形成「宫格弹层 → 卡片下钻弹层」两层叠层，BottomSheet 均 Portal 到 body、后开者在 DOM 后自然居上，内层关闭回到宫格弹层）。

### 3.3 数据与状态

- 所有数据拉取、轮询、缓存逻辑不变（卡片只换了挂载位置）。
- 宫格弹层打开时卡片才渲染（内容已在页面 state 中，无额外请求）。

## 4. 台账页改造（`apps/mobile-portal/src/app/(main)/ledger/page.tsx`）

- **拉取层不变**（仍 `PAGE_SIZE=15`/页，避免混用 pageSize 破坏后端 offset 计算），改**显示层控制**：新增 `visibleCount` 状态，首屏只渲染前 5 条；「展开更多（共 N 条）」每次 +10。
- 当 `visibleCount` 逼近已载条数且还有更多页时，点「展开更多」先取下一页再放行显示。
- **删除 IntersectionObserver 触底自动加载**（改为纯手动按钮，防滚动即翻页回到长页）。
- 筛选/搜索/公司/重试变化时 `visibleCount` 重置回 5（现有依赖数组已驱动重取）。
- 汇总条、筛选 chips、行样式、focusPmi 桥接弹层全部不动。

## 5. 组件与样式约定

- 弹层复用 `BottomSheet`（已具备 Portal/body 滚动锁/幽灵点击防护/Escape）；卡片复用 `SectionCard`/`MetricCard`/`m-tile`。
- 宫格 tile 视觉遵循 cgzxui：瓷面卡（neu 静态卡）+ 图标井 + 17px 粗体标签；禁渐变按钮/emoji 图标。
- 空数据组：tile 恒显，弹层内沿用各卡片现有空态。

## 6. 验收

- 量化：数据库页总高 ≤ ~1300px（≈1.5 屏）；台账首屏（前 5 条）≤ ~1300px；展开更多可用至全部 N 条。
- 交互回归：下拉刷新、区间/公司切换、指标卡跳转、卡片下钻弹层（两层叠层）、筛选重置、focusPmi 直达、今日要报秒回均不回退。
- 单测无涉及（纯前端重组，无新数据逻辑）；用 Playwright 实测页高与宫格弹层可用性作验收记录。

## 7. 风险

- 两层弹层叠放的滚动锁恢复顺序（BottomSheet 各自记忆 prev，关闭顺序天然正确）——验收时专测。
- 宫格收纳后「扫描全貌」变「两次点击」——以首屏保留趋势图+指标卡对冲，且各宫格弹层内信息完整不减。
