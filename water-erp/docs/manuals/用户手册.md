# 用户操作手册（按端简版）

## :3005 采购管理端（leader/staff/admin）
1. **项目管理**：新建项目（上传需求/立项表 AI 提取）→「递交审核」→ admin「审核通过/驳回（理由）」→ 阶段推进（每阶段材料齐备才可完成）
2. **任务计划与团队**（项目详情内）：添加计划条目（责任人/起止）→「报审计划」→ admin 受理；团队成员添加与分工
3. **采购文件**：tender-write 编制（AI 导入/评分标准）→ tender-review 审查（规则+语义）
4. **开标确认**：评分标准 → 指派主持人 → 按时开标 → 归档（签字闭环闸门）
5. **供应商管理**：审批/黑名单（拉黑必填原因并通知供应商；可解除）/奖惩记录/人员类别标注
6. **专家管理**：入库状态（审核入库/暂停/退库）；抽取（回避自动比对）
7. **数据库**：项目中标结果联查、统计洞察
8. **归档管理**：卷台账/四性检测/ASIP 导出/移交登记表

## :3002 公共门户（免登录）
公告公示、开标大厅直播、供应商注册入口。

## :3004 供应商门户
注册（协议+信用代码查重）→ 等待审核 → 投标（下载/加密递交/截止后不可改）→ 开标解密 → 中标通知书（已读回执）→ 履约。

## :3006 专家端
邀请确认（RSVP）→ 签到/回避确认/保密承诺 → 评审打分 → 异议工单。

## :3007 开评标主持端
开标流程控制、解密、评标签字包、归档回流。

> 各端详细界面流程见 docs/ 下专项审计文档；账号与口令规则见 ACCOUNTS.md。
