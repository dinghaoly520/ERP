## 模块

```
apps/api/src/common/crypto/x509/
├── der-parser.ts      # 最小 ASN.1/DER TLV 解析（零新依赖）
├── x509-cert.ts       # X.509 v3 结构化 + pemToDer + verifyCertSignature（sm-crypto SM3-SM2）
├── chain-verifier.ts  # leaf→中间→根：逐级验签 + 时间窗 + CA 标志 + 深度上限
├── trust-store.ts     # TRUSTED_CA_DIR 信任锚（PEM 落盘，启动加载）
├── revocation.ts      # RevocationChecker 接口（阶段1 空实现，阶段2 接 CRL）
└── *.spec.ts          # 共生单测
```

数据模型（SupplierCert 加列，迁移 create-only + db execute + resolve）：
- `rawCert String?`（DER base64，唯一事实源；null=存量/伪证书兼容）
- `issuerDn String?`、`certSource String @default("mock")`

## 绑定流（唯一业务改动点）

1. 带 `rawCert`（DER base64）→ 服务端解析为唯一事实源，声明值交叉校验
   （不一致 → 400 CERT_FIELDS_MISMATCH）
2. 链校验闸：信任锚目录有锚 + rawCert 存在 → 必须过链；失败默认 400 CERT_UNTRUSTED
   （`CERT_CHAIN_ENFORCE=false` 降级告警）；无锚/无 rawCert → 跳过 + audit log
3. PoP（证明持有私钥）：`GET profile/cert/challenge` 下发 nonce（Redis 5min TTL）→
   前端 `adapter.sign` → 绑定请求带 nonce+signature → `signatureService.verify`
   （失败 400 CERT_POP_FAILED）。mock 轨同构（adapter.sign 都能做）。
4. 现有全部闸门保留。

投递/开标端不加链校验（签时快照口径）；A-13 到期提醒逻辑不动（expiresAt 来源变可靠）。

SM2 验签口径：证书签名值 DER(r,s) → r||s hex；tbsCertificate 原始字节为消息；
sm-crypto `doVerify(hash:true)` 默认 userId `1234567812345678` 与 OpenSSL 默认 SM2 ID 对齐
（以夹具实测为准，若有出入在 verifyCertSignature 内消化）。

## 配置

```
TRUSTED_CA_DIR=./apps/api/.data/trusted-ca   # 空目录=无锚=链闸跳过（现阶段默认）
CERT_CHAIN_ENFORCE=true                      # 有锚时失败即拒绝；false=只告警
```
