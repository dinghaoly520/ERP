# 谈判采购系统操作指引

谈判采购在本系统的特点：不发采购公告、采购邀请书替代公告位、先评标后多轮报价、最终轮最低价定标。全过程分七步。

## 一、立项（采购管理工作台 :3005 → 项目管理）
新建项目，采购方式选「谈判采购」，填预算、申请部门、立项材料。立项后走采购流程阶段模板；谈判采购跳过「采购公告公示」阶段。

## 二、采购文件编制（03 采购文件阶段）
在项目管理的采购文件阶段编制/上传附件——阶段附件是采购文件的权威源。谈判项目的文件不进公告附件位（谈判不发公告），后续经「谈判配置」交付给受邀供应商。

## 三、供应商邀请（五步向导，回执确认须不少于 3 家）
1. 供应商要求：智能推荐+手动补选候选；
2. 审核候选：跨公司自动剔除；
3. 确认通知：固定模板语句，回执短链经站内信+短信发出（供应商在回执页确认或婉拒；确认即入册并自动建项，婉拒移出候选并计连拒预警）；
4. 附件选择与谈判配置下发（仅谈判有此步）：设定获取窗口、选定文件指针，受邀供应商在供应商门户 :3004 的项目详情页获取谈判文件（含专用下载端点）；
5. 供应商确认：回执看板跟进，可代回应；阶段完成闸=确认回执不少于 3 家。
注意：谈判配置存于服务端缓存（30 天有效期），供应商获取窗口关闭后需重新下发。

## 四、专家抽取（评分模板无价格分）
专家抽取六步向导（配额、回避、抽取、确认）；谈判评分模板=合格制：商务 30 分+技术 70 分，无价格分。专家在专家门户 :3006 完成身份五项核验，凭评标室口令获取谈判文件。

## 五、投递与开标（须不少于 3 家已接受邀请）
受邀供应商在 :3004 投递响应文件（双信封加密）；:3005 开标确认面板完成按时开标；现场解密、唱标在开评标管理端 :3007。

## 六、评标与报价轮（谈判核心：先评标、后报价）
1. :3007 启动评标，专家在 :3006 评分（合格制）；
2. 评标至报告确认、组长末签完成；
3. 报价轮：评标完成后才可开轮——开轮 → 供应商在 :3004 报价（单位：元）→ 封标 → 公布 → 关闭；可再开新一轮；
4. 结果生成：全部报价轮关闭后，最终轮报价换算（÷10000，万元口径回写开标记录）取合格组最低价定标，超限价判废。
限制：评标结果生成后不可再新增报价轮；迟到最后报价不参与定标。

## 七、收尾与归档
评标结果 → 中标/成交文书（:3005）→ 评标签字包（:3007 打印签字回传登记）→ 评标回流包 → :3005 完整归档（闸门=签字闭环+回流已接收）→ 项目管理「完成项目」（若关联投标项目仍有活动态会被拦，先完成开评标收尾）。台账自动落轮次；中途终止走「终止」并填原因（落异常轮次），不要删除项目。
