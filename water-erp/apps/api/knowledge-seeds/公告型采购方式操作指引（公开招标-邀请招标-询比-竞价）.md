# 公告型采购方式操作指引（公开招标 / 邀请招标 / 询比 / 竞价）

四方式共用主干：立项 → 采购文件编制 → 公告编写发布 → （邀请招标加邀请步）→ 专家抽取 → 投递与开标 → 评标与收尾。

## 公开招标
可不经立项向导、由信息发布中心直接发布公告（公告直建项目：系统自动补建最小项目管理并回填关联）。

## 邀请招标
= 公告（可设定向白名单）+ 第三步供应商邀请：定向白名单入册（投递前、限本公司库）；投递前须不少于 3 家已接受邀请。采购文件阶段徽章显法定名「招标文件」。

## 询比采购
快节奏：截止 3 天/5 天配置；其余同主干。

## 竞价采购
单轮密封报价、唱标价即终价（豁免报价轮闸）；其余同主干。

## 公共要点
- 公告三步向导：编写 → 定时/立即发布（定时须 +08:00 时区）→ 关联采购文件；
- 专家抽取六步向导后经 :3005 开标确认面板替换/确认；启动评标校验在 :3007；
- 供应商在 :3004 下载/投递（双信封）；截标后 10 分钟开标规则；
- 收尾：评标结果 → 签字包 → 回流包 → :3005 完整归档。
