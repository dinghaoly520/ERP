# 公告型采购方式操作指引（公开招标 / 邀请招标 / 询比 / 竞价）

主干：立项 → 采购文件编制 → 供应商组织（公告型=公告编写发布；邀请型=供应商邀请，2026-11-12 流程互换后邀请招标/直接采购不再发采购公告）→ 专家抽取 → 投递与开标 → 评标与收尾。

## 公开招标（2026-11-20 入项目管理全流程）
与邀请招标同构：采购需求 → 采购立项 → 招标文件（法定名）→ **招标公告公示** → 专家抽取 → 开标评标 → 定标 → 合同。不发供应商邀请，供应商经 :3004「项目机会」公告公开参与；也可不经立项向导、由信息发布中心直接发布公告（公告直建项目：系统自动补建最小项目管理并回填关联）。公告/文件模板为招标人口吻（招标公告/招标文件/招标人）。

## 邀请招标
第三步供应商邀请（定向邀请函+回执）：定向白名单入册（投递前、限本公司库）；投递前须不少于 3 家已接受邀请。采购文件阶段徽章显法定名「招标文件」。不发布采购公告（2026-11-12 流程互换）。

## 询比采购
快节奏：截止 3 天/5 天配置；其余同主干。

## 竞价采购
单轮密封报价、唱标价即终价（豁免报价轮闸）；其余同主干。

## 公共要点
- 公告三步向导：编写 → 定时/立即发布（定时须 +08:00 时区）→ 关联采购文件；
- 专家抽取六步向导后经 :3005 开标确认面板替换/确认；启动评标校验在 :3007；
- 供应商在 :3004 下载/投递（双信封）；截标后 10 分钟开标规则；
- 收尾：评标结果 → 签字包 → 回流包 → :3005 完整归档。
