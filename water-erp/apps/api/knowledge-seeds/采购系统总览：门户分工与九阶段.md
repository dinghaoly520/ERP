# 采购系统总览：门户分工与流程阶段

## 门户分工
- 信息门户 :3002：公告浏览、全角色登录入口（登录后按角色跳转对应门户）；
- 供应商门户 :3004：注册、获取采购文件、投递（双信封加密）、报价轮、资质管理；
- 采购管理工作台 :3005：项目管理（立项/阶段推进）、采购文件编制、供应商邀请、信息发布中心（公告）、专家库与抽取、开标确认面板、归档；
- 专家门户 :3006：身份核验、获取文件、评分、报告确认；
- 开评标管理端 :3007：开标大厅、评标管理、签字包、回流包（现场端）；
- 水叮当 :3008：AI 助手（公共）；大屏 :3010；移动驾驶舱 :3011（只读）。

## 采购流程九阶段（canon，项目管理阶段模板）
采购需求 → 采购立项 → 采购文件 → 供应商邀请 → 采购公告公示 → 专家抽取 → 开标评标 → 定标 → 合同；直接采购尾段=直接采购备案表。各方式按模板套用（谈判无公告阶段；公开招标可由公告直建项目）。

## 投标项目阶段机（执行侧）
文件下载 → 加密投递 → 在线开标 → 专家评标 → 资料归档（单向棘轮：只前进可跳步）；另有已流标终态。

## 通用闸门
- 按时开标确认：:3005 开标确认面板（主持人指派、延时/按时开标）；
- 启动评标与评标中流标：:3007；
- 完整归档：:3005（闸门=评标签字闭环+回流包已接收）；项目管理归档若有关联投标项目活动态会先被拦；
- 供应商邀请确认通知：固定模板语句+回执短链（站内信+短信）；
- 金额口径：开标记录侧=万元；报价轮与评标结果/文书=元。
