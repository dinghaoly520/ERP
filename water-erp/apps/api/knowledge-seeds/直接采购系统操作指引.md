# 直接采购系统操作指引

直接采购特点：单一成交对象、不评分、尾段为「直接采购备案表」。

1. 立项（:3005 项目管理）：采购方式选「直接采购」，立项时含拟定供应商与商谈时间；
2. 采购文件编制：直接采购模板（03 阶段附件为权威源）；
3. 04 交付轨道二选一：公告轨=发布公告（须公布采购理由+拟定供应商）或邀请轨=两步邀请（确认通知→供应商确认，跳过谈判的配置下发步）；
4. 专家抽取：可配专家（不评分），专家做定性核对；
5. 投递与开标：单家投递（法定家数=1）；
6. 评标=定性审查：专家核对转定性结论；若出现多家可评，系统直接拒绝（直接采购只允许单一成交对象）；
7. 收尾：评标签字包标注「不评分」；回流归档后走「直接采购备案表（附件6）」末段，项目归档以备案表收尾。
