# 设计决策说明

- **复用首页视觉骨架**：直接引入 `UnifiedHeader` 和 `FlowBackdrop` 组件，与首页保持完全一致的顶栏导航和背景效果，确保品牌一致性。

- **返回首页按钮**：沿用 procurement-portal 同款的 `flow-back` 样式类（带左箭头 SVG），放在 Header 正下方，符合用户从首页进入子页面的视觉预期。使用 `router.push('/')` 进行客户端导航。

- **FAQ 卡片网格布局**：采用响应式 3 列网格（移动端 1 列、平板 2 列、桌面 3 列），每张卡片包含图标、分类标签、问题标题和答案描述，结构清晰且信息密度适中。

- **设计系统对齐**：卡片使用 `rounded-2xl` 圆角、1px 细边框、hover 阴影、品牌蓝 `#064ea2` 强调色，底部渐变装饰线复用首页弧线的蓝绿配色（`#0b59ad` → `#18a56c`），底部的 CTA 区域复用 `flow-cta` 类，整体与 `.impeccable.md` 设计规范一致。

- **内容覆盖常见问题场景**：FAQ 涵盖供应商注册、密码找回、投标流程、文件下载、评标结果查看、客服联系 6 个高频问题，贴合水务采购平台的实际业务场景。
