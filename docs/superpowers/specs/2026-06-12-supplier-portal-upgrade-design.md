# 供应商门户 3003 全面升级设计

日期：2026-06-12

## 背景

供应商门户运行在 `water-erp/apps/supplier-portal`，技术栈为 Vue 3 + Vite + Element Plus + Pinia，端口 3003。当前门户已经覆盖入驻状态、企业资料、资质、联系人、信息变更、招标信息、我的投标、公告、消息、评价记录等核心功能，但整体体验仍偏“菜单式后台”。

本次升级目标是把供应商门户升级为“供应商业务驾驶舱 + 投标全流程工作台”，同时强化四川水发 / 蜀水云采的政企可信、水务品牌和现代业务效率感。

## 目标

1. 全面升级内容组织、功能动线和 UI 视觉。
2. 保留现有 Vue、Element Plus、Pinia、API 调用和后端接口结构。
3. 不修改数据库结构。
4. 优先提升 3003 端口可见页面的整体观感和供应商操作效率。
5. 实施后通过构建、浏览器访问和控制台检查验证。

## 信息架构设计

门户从“功能菜单”调整为“业务任务驱动”。保留现有路由，优化导航展示层级：

- 工作台
- 投标中心
  - 招标机会（原招标信息）
  - 投标进展（原我的投标）
- 企业档案
  - 入驻状态
  - 企业信息
  - 资质与证照（原资质管理）
  - 联系人
  - 资料变更申请（原信息变更）
- 信息中心
  - 公告公示（原信息公告）
  - 消息通知
  - 履约评价（原评价记录）

## 首页工作台设计

首页是本次升级重点。内容按供应商日常任务重排：

1. 供应商状态总览
   - 显示企业名称、入驻状态、退回原因、资料完整度。
   - 状态为退回补正时，突出补正原因和入口。

2. 今日待办
   - 资料不完整：引导完善企业资料。
   - 资质即将到期：引导更新资质。
   - 存在 SUBMIT 阶段招标：引导立即投标。
   - 有未读消息：引导处理消息。
   - 有待审变更：引导查看变更进度。

3. 投标机会
   - 展示最新招标项目、阶段、截止时间、关键操作。
   - 对提交期、即将截止项目强化颜色和按钮。

4. 投标进展
   - 展示供应商已参与项目的状态分布和关键入口。
   - 用业务化语言表达草稿、已提交、撤回、评审中、归档等状态。

5. 公告与消息
   - 公告按类型展示：招标公告、中标公示、政策法规、平台通知。
   - 未读消息优先展示，并保留跳转入口。

## 功能体验设计

### 列表页

招标机会、投标进展、公告公示页统一升级：

- 顶部有清晰页面标题、说明和统计摘要。
- 筛选区更突出，减少传统表单堆叠感。
- 列表项突出业务状态、截止时间、类型标签和主要操作。
- 空状态提供下一步说明。
- 操作按钮文案更直接。

### 详情页和提交页

如实施阶段时间允许，继续升级：

- 招标详情页强化项目基本信息、阶段进度、时间节点、投标入口、风险提醒。
- 提交标书页强化步骤感、材料检查、提交确认和错误提示。

### 表单页

企业信息、资质、联系人、变更申请页采用一致的分区和提示：

- 分区标题表达资料用途。
- 必填项和审核状态更明显。
- 保存、提交、撤回等按钮优先级明确。
- 错误提示和空状态更业务化。

## UI 视觉设计

整体方向：政企可信 + 水务品牌 + 现代业务驾驶舱。

### 色彩

- 保留深蓝作为主色，体现政企可信。
- 增加水蓝、青色、绿色作为业务辅助色。
- 风险和截止提醒使用橙色/红色，减少滥用。

### 布局

- 侧边栏改为更强品牌感的导航区域。
- 顶部栏强化搜索、消息、用户状态。
- 工作台采用 hero 区 + 待办 + 数据卡 + 项目列表的分层结构。
- 卡片间距、标题层级、按钮优先级统一。

### 组件语言

新增或强化通用 CSS 类：

- 业务 Hero 区
- 任务卡片
- 状态徽章
- 项目卡片
- 时间节点 / 截止提醒
- 页面头部
- 现代筛选区
- 空状态

继续使用 Element Plus，不引入新 UI 框架。

## 风险与处理

- 部分深层业务体验受现有 API 字段限制，实施时优先基于现有字段重排和增强展示。
- 页面文件可能已有较多内联样式，实施时优先提取通用视觉到 `global.css`，避免继续堆叠重复样式。
- 若构建暴露类型或模板错误，按页面逐一修复，保持现有业务功能可用。
