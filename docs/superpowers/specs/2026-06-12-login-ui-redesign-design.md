# 3002-3005 登录界面 UI 重设计规格

日期：2026-06-12  
项目：智慧水发 · 蜀水云采 ERP 系统  
范围：`3002`、`3003`、`3004`、`3005` 四个端口的登录界面视觉升级

## 1. 背景与目标

本次重设计面向四个实际运行端口的登录页：

| 端口 | 实际应用 | 登录页定位 |
| --- | --- | --- |
| `3002` | mall 电子商城 | 蜀水云采电子商城，一站式水利工程物资采购平台 |
| `3003` | supplier-portal 供应商门户 | 供应商登录、注册、投标、进度跟踪入口 |
| `3004` | web 采购管理平台 | 内部招采运营、信息发布、供应商/专家管理入口 |
| `3005` | expert-portal 专家评审工作站 | 专家独立评审、在线评分、过程留痕入口 |

目标是将四个登录页升级为高端、科技感、未来感的企业级界面，同时保证每个端口贴合自身模块特色。设计方向采用：**统一“数字水务驾驶舱”体系 + 四端行业化差异**。

本规格仅描述 UI 与交互设计，不改变现有登录 API、鉴权、角色校验或跳转逻辑。

## 2. 统一设计体系

### 2.1 品牌元素

所有登录页统一使用：

- Logo：`/Users/qihao/Desktop/ERP/water_erp_web/assets/logo.jpg`
- 公司名称：四川水发集团
- 系统品牌语：智慧水发 · 蜀水云采
- 基础主色：深水蓝、品牌蓝、霓虹青蓝

建议色值：

| 用途 | 色值 |
| --- | --- |
| 深水蓝 | `#061427` |
| 品牌蓝 | `#064ea2` |
| 霓虹青蓝 | `#22d3ee` |
| 白色文字 | `rgba(255,255,255,0.92)` |
| 次级文字 | `rgba(203,213,225,0.68)` |
| 玻璃卡片背景 | `rgba(8,20,40,0.68)` |
| 玻璃卡片边框 | `rgba(148,213,255,0.18)` |

### 2.2 统一页面结构

四个端口保持同一基础结构：

1. 背景层：深色渐变、水波/网格/光轨等数字水务氛围。
2. 品牌区：Logo、四川水发集团、系统品牌语。
3. 业务视觉区：模块标题、模块说明、三项业务能力标签。
4. 登录区：玻璃拟态登录卡片，包含标题、描述、用户名/密码输入框、主按钮、必要辅助链接。
5. 底部：版权或安全提示，不显示测试账号。

### 2.3 统一交互

- 输入框聚焦时显示蓝青色高亮边框和轻微外发光。
- 登录按钮使用蓝色到青蓝色渐变，并有 hover 高光。
- Loading 状态沿用现有逻辑，但按钮文案与模块匹配。
- 错误提示逻辑不变。
- 所有测试账号提示全部移除。
- 保留当前必要跳转：
  - `3002`、`3004`、`3005` 保留“返回门户”。
  - `3003` 保留“立即注册供应商”。

### 2.4 响应式原则

- 桌面端：沉浸式双栏布局，视觉区与登录卡片并列。
- 平板端：压缩视觉区，保留模块标题与登录卡片。
- 手机端：隐藏复杂装饰，采用品牌头部 + 登录卡片的垂直布局，优先保证可读性和输入体验。

## 7. 实施边界

本设计允许修改：

- 登录页 JSX / Vue 模板与样式
- 登录页本地视觉组件或装饰元素
- 静态资源引用方式，使四端都使用指定 Logo
- 响应式布局与视觉文案

本设计不修改：

- API 地址与请求结构
- 登录认证逻辑
- Cookie / JWT 逻辑
- 角色校验逻辑
- 登录成功后的业务跳转
- 非登录页面的业务功能

## 8. 验收标准

完成后应满足：

1. `3002`、`3003`、`3004`、`3005` 四个登录页均使用统一品牌体系。
2. 每个端口的标题、文案、强调色和视觉装饰贴合自身模块定位。
3. 所有登录页都使用四川水发集团 Logo 和公司名称。
4. 所有测试账号提示均已移除。
5. 现有登录、校验、跳转逻辑保持不变。
6. 桌面端、平板端、手机端均可正常阅读和输入。
7. UI 整体呈现高端、科技感、未来感，同时保持企业级系统的稳定和可信。
