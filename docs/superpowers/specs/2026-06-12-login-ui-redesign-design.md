# 3002-3005 登录界面 UI 重设计规格（亮色简约版）

日期：2026-06-13  
项目：智慧水发 · 蜀水云采 ERP 系统  
范围：`3002`、`3003`、`3004`、`3005` 四个端口的登录界面视觉升级

## 1. 背景与目标

本次重设计面向四个实际运行端口的登录页：

| 端口 | 实际应用 | 登录页定位 |
| --- | --- | --- |
| `3002` | mall 电子商城 | 蜀水云采电子商城，一站式水利工程物资采购平台 |
| `3003` | supplier-portal 供应商门户 | 供应商登录、注册、投标、进度跟踪入口 |
| `3004` | web 采购管理平台 | 内部招采运营、信息发布、供应商/专家管理入口 |
| `3005` | expert-portal 专家评审工作站 | 专家独立评审、在线评分、过程留痕入口 |

最终方向调整为：**亮色系、极简企业科技风、左侧品牌文案 + 右侧登录框**。目标是清爽、克制、高端、科技、可信，避免暗色大屏式复杂装饰。除登录框外，其他元素尽可能简约，只承担品牌识别与模块区分。

本规格仅描述 UI 与交互设计，不改变现有登录 API、鉴权、角色校验或跳转逻辑。

## 2. 统一设计体系

### 2.1 品牌元素

所有登录页统一使用：

- Logo：`/Users/qihao/Desktop/ERP/water_erp_web/assets/logo.jpg`
- 公司名称：四川水发集团
- 系统品牌语：智慧水发 · 蜀水云采
- 基础色：白色、浅灰蓝、淡水蓝
- 强调色：按端口模块差异使用橙、绿、金、紫

建议色值：

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#f6f9fd` |

| 主文字 | `#0f172a` |
| 次级文字 | `#64748b` |
| 卡片边框 | `#dbeafe` |
| 输入边框 | `#d7e3f2` |

### 2.2 统一页面结构

四个端口保持同一基础结构：

1. 背景层：浅色渐变 + 极淡水波线/细网格/柔和光晕。
2. 左侧信息区：Logo、四川水发集团、系统品牌语、模块标题、一句模块说明、2-3 个极简标签。
3. 右侧登录区：白色登录卡片，轻阴影，清晰输入框，模块强调色按钮。
4. 底部信息：简短安全提示或版权信息。

### 2.3 简约约束

- 不使用复杂浮动指标卡、矩阵、密集光轨、大量装饰元素。
- 登录框是页面视觉中心。
- 左侧信息区只保留必要文案与少量标签。
- 背景装饰必须低对比、低干扰。
- 所有测试账号提示全部移除。

### 2.4 交互约束

- 输入框聚焦时显示模块强调色边框和轻微外发光。
- 登录按钮使用模块强调色渐变或纯色按钮。
- Loading 状态沿用现有逻辑，但按钮文案与模块匹配。
- 错误提示逻辑不变。
- 必要跳转保留：
  - `3002`、`3004`、`3005` 保留“返回门户”。
  - `3003` 保留“立即注册供应商”。

### 2.5 响应式原则

- 桌面端：左文案 + 右登录框双栏。
- 平板端：压缩左右间距，保持双栏或上下布局。
- 手机端：上下布局，品牌信息精简，登录框优先展示，页面允许纵向滚动。

## 7. 实施边界

允许修改：

- 四个登录页的 JSX / Vue template / scoped CSS
- 静态 logo 引用方式
- 登录页视觉文案与响应式布局

不修改：

- API 地址与请求结构
- 登录认证逻辑
- Cookie / JWT 逻辑
- 角色校验逻辑
- 登录成功后的业务跳转
- 非登录页面业务功能
- 包依赖

4. 每页都使用四川水发集团 Logo 和公司名称。

8. 构建与登录页路由文本检查通过。
