# 项目变更体系设计（2026-11-11）

## 背景与裁定链

用户裁定（2026-11-10/11 会话）：业务公告应纳入项目流程而非公告发布中心；「变更」可发生在开标前任一节点（不是固定阶段）；项目基本信息的**唯一人工编辑通道 = 变更弹窗**，每次变更必须留痕（含理由）。本设计为该裁定链的第一批落地（公告中心收口、资格预审节点另批）。

## 1 · 入口与权限

- 按钮「⟳ 变更 / 补遗」位于**项目标题行右侧**（方案 A，2026-11-11 用户选定）
- **按钮状态矩阵**：

| 场景 | 展现 |
|---|---|
| 项目创建人本人 + 开标前 | 「⟳ 变更 / 补遗」（可发起变更/补遗、可看记录） |
| 项目创建人本人 + 开标后 | 「变更 / 补遗记录」（仅查看；点发起态按钮则提示「开标后不可修改标前数据」） |
| 其他账户（leader/admin 只读视野等） | 「变更 / 补遗记录」（仅查看） |

- 权限口径与 PmiOwnershipGuard 写权限一致（staff 本人项目；他人项目只读）
- 「开标后」判定 = 关联 BidProject 进入 OPENING 阶段起（与现有 isBidLocked「开标已确认」语义同源）；提示文案固定为「开标后不可修改标前数据」

## 2 · 变更范围与阶段闸门

- 左栏**项目基本信息改为纯展示**：移除全部直接编辑入口；人工编辑只走变更弹窗
- 弹窗内字段**按阶段分组**，闸门 = 只解锁「项目已推进到」的组：
  - 基本信息组（名称/编号/类别/预算/需求人/需求单位…）
  - 采购文件组（资格要求/供货范围/质量要求…）
  - 公告组（公示起止/开标时间/截止时间）
  - 未到达阶段的组禁用，标注「未进入 ×× 阶段，不可变更」
- **例外（不纳入变更范畴）**：①供应商名单、专家名单——AI 识别可能不准，需随时人工维护，保持既有邀请/抽取流程卡的常规编辑；②系统自动写入（AI 提取/上传解析）——建档录入非人工变更，维持现状

## 3 · 变更流程（弹窗三步，全窗口内完成）

```
① 选类型：⟳ 变更（修改已发布信息，登记轮次）｜ 📄 补遗（追加说明，不改原数据）
② 编辑：分组字段表单 + 阶段闸门 + 必填「变更理由」
③ 保存 = 字段更新 + 变更登记（轮次·类型·理由·字段级 from→to·操作人·时间）
```

- 补遗沿用既有补遗链路（定向通知已获取文件供应商）

## 4 · 变更记录模型（新表 `ProjectChangeRecord`）

| 字段 | 说明 |
|---|---|
| id / projectManagementItemId | 归属项目 |
| round | 轮次（项目内自增，变更与补遗共序） |
| type | 'CHANGE'（变更）/ 'ADDENDUM'（补遗） |
| reason | 变更理由（必填） |
| changeset | JSON：`[{ field, label, from, to, stageKey }]` 字段级 diff |
| announcementId | 关联的变更/补遗公告（如有） |
| operatorId / operatorName | 操作人（displayName 快照口径） |
| createdAt | 时间 |

记录查看入口 = 变更/补遗按钮的「记录」形态（弹窗列表：轮次·类型·摘要·理由·操作人·时间，点开看 diff）。**不在时间信息轴上加节点**（2026-11-11 用户裁定）。

## 5 · 开标时间变更 → 强制变更公告

- 变更涉及开标时间 → 数据保存成功后**弹窗内**进入「变更公告」编辑与发布（与其他公告同款窗口操作：内容编辑 + 发布配置（范围/时间/阳光勾选））
- 未发布则变更记录挂「公告待发」状态并在项目上提醒（红标）；发布完成即闭环
- 变更公告发布且勾选阳光 → 推 **SCM0003**（`/dataService/import/announcementChanges`，round = 变更轮次，与文档 changes 语义对齐）

## 6 · 明确不做（本批）

- 时间信息轴不加变更节点（记录只在弹窗中）
- 公告发布中心收口（政策/平台 only）——后续批次
- 资格预审节点（公告类专用）——挂起待后续裁定
- SCM0005 成交结果（挂合同流程卡）——后续批次

## 7 · 实现顺序

1. 后端：ProjectChangeRecord 模型+迁移；变更登记端点（字段白名单+阶段闸门+理由必填+diff 快照）；PMI 人工编辑端点收紧（仅变更通道；系统提取写入白名单保留）
2. 前端：标题行按钮（状态矩阵）+ 变更/补遗弹窗（三步）+ 左栏基本信息只读化
3. 变更记录列表与详情（弹窗内）
4. 开标时间强制公告（弹窗内编辑+发布配置）+ SCM0003 推送挂点
