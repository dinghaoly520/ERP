## 四、测算依据与测算方法

### 4.1 费用构成框架（标准第 5 章）

建设项目费用 = 项目建设费 + 项目建设其他费 + 预备费。本次报价对应项目建设费：成品软件购置费 0（全定制开发）、**定制软件开发费**（测算主体）、**数据建设费**、**系统集成费**、**标准规范编制费**、系统迁移费 0（新建系统）、其他（硬件/建安/云资源/网络）0（集团提供运行环境）。

### 4.2 定制软件开发费测算公式链（标准 5.2.3）

```
① UFP = 10×ILF + 7×EIF + 4×EI + 5×EO + 4×EQ        （估算功能点计数法，5.2.3.5）
② US  = Σ(计数项 × 重用程度)                          （高1/3、中2/3、低1，表C.6）
③ S   = US × CF                                       （概算/预算阶段 1.21，5.2.3.5）
④ SWF = ST × NF                                       （预算阶段仅计两项，5.2.3.5 注4）
⑤ AE  = S × SWF × PDR（人时）                          （CSBMK P50=6.54，±20% 浮动）
⑥ SDC = AE ÷ 174 × F                                  （HM=174；F=2.0 万元/人月，附录 D）
```

### 4.3 代码实测计数方法（本报告差异化基础）

- **数据功能**：126 个 Prisma 数据模型逐个按 ILF/EIF 识别规则判定（剔除代码表/纯关联表/技术表，强依赖主从实体按 RET 归并）→ **77 个 ILF；EIF=0**（系统边界自包含，外部依赖均为服务调用而非数据组引用）；
- **事务功能**：674 个端点（API 673 + OCR 1）按处理本质分类（维护数据/改变行为→EI；含计算/衍生输出→EO；简单提取→EQ），按 C.7 基本过程归并（同资源 list/detail 合并、跨门户同数据视图合并、暂存并入提交等 59 处）→ **615 个基本过程（EI 333 / EO 104 / EQ 178）**；
- **应用边界**：整个平台为一个应用边界，9 门户是同一应用的交互通道，跨门户重复功能只计一次——防止多门户架构导致的高估；
- 计数全程脚本提取 + 人工逐项判定，**674 行端点归并明细与 77 组模型判定清单全部留痕**（附录），可提交第三方复核。

| 特性 | 明示要求/建设实据 | 取值 |

| 可靠性 | 招采交易业务连续性、定时备份与归档留存（SHA-256 校验） | +1 |
| 可移植性 | 云端/本地多种部署形态，docker-compose 全栈容器化 | +1 |

SWF（业务组）= 1.00×1.10 = **1.10**；SWF（AI 组）= 1.50×1.10 = **1.65**。SL/DT 按预算阶段不计取（结算口径下补计，见第十一章）。

### 5.6 人月费用单价与折算系数（附录 D）

F = 2.0 万元/人月（9000×2.265，含企业管理费、规费、利润、税费）；HM = 174 人时/人月。数据建库/治理 1.5 万元/人月、数据梳理加工 1.2 万元/人月（表 D.1）。
