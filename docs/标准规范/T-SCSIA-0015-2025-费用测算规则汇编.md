## 1. 总体框架

标准覆盖三类项目：

| 项目类型 | 费用构成 | 条款 |
|---|---|---|
| **建设项目** | 项目建设费 + 项目建设其他费 + 预备费 | 第 5 章 |
| **信息化服务项目**（购买服务/租赁） | 成品软件租赁、设备租赁、定制开发软件租赁、其他租赁 | 第 6 章、附录 L |
| **运维项目** | 基础设施维保费、硬件设备维保费、软件运维费、等保测评/密评/安全服务费、其他运维服务费 | 第 7 章、附录 J/K |

**建设项目总投资构成（附录 A 表 A.1）**：

```
总投资 = 一、项目建设费 + 二、项目建设其他费 + 三、预备费

一、项目建设费（1+2+3+4+5+6+7）
  1 成品软件购置费
  2 定制软件开发费
  3 数据建设费（3.1 资源购置 / 3.2 服务购置 / 3.3 资源建库 / 3.4 加工 / 3.5 模型搭建）
  4 系统集成费
  5 标准规范编制费
  6 系统迁移费
  7 其他与项目建设有关的费用（7.1 建筑安装 / 7.2 硬件购置 / 7.3 内场适应性改造 /
     7.4 外场设备安装 / 7.5 建设期电费 / 7.6 建设期云资源租赁 / 7.7 建设期网络租赁）

二、项目建设其他费（1~14）
  项目管理费 / 项目建议书 / 可研 / 初设(服务需求) / 监理 / 造价咨询 / 软件测评 /
  等保测评 / 密评 / 涉密分保测评 / 招标代理 / 项目审计 / 后评价 / 数据安全评估

三、预备费（基本预备费）
```

注：构成可按项目实际裁剪；确需考虑建设期利息的按国家/行业规定另计（表 A.1 注 2）。

## 2. 通用参数：人月费用单价（附录 D）

**公式**：人月费用单价 = 人月工资 × 人月系数

- 人月工资 B = 9000 元/月（依据四川省人社厅"信息传输、软件和信息技术服务业"工资价位 P50 等）
- 人月系数上限 = 2.265 = 1(工资) + 0.45(企业管理费) + 0.39(利润) + 0.425(规费)
- **基准单价 = 2.0 万元/人月**；人月按 21.75 天计；人天费用 = 人月单价 ÷ 21.75

**表 D.1 分类人月费用单价**：

| 分类 | 分类细项 | 比例系数 | 单价（万元/人月） |
|---|---|---|---|
| 软件开发 | 软件开发人员 | 1.0 | 2.0 |
| 数据服务 | 数据测试及梳理等人员 | 0.6 | 1.2 |
| 数据服务 | 数据治理、建库等人员 | 0.75 | 1.5 |
| 数据服务 | 数据分析、算法模型等人员 | 1.0 | 2.0 |
| 运维服务 | 运维服务人员 | 0.6 | 1.2 |
| 涉密运维服务 | 涉密运维服务人员 | 0.75 | 1.5 |
| 安全服务 | 安全服务人员 | 0.9 | 1.8 |

## 3. 建设项目费用

### 3.1 项目建设费（5.2）

#### 3.1.1 成品软件购置费（5.2.2）

**公式**：成品软件购置费 = ∑（软件授权协议单价或市场单价 + 单套软件实施工作量 × 人月费用单价）× 数量

要点：
- 成品软件 = 无需开发、可直接安装部署（OS/数据库/中间件/虚拟化/安全软件/行业应用软件）
- 原则上由省级和市（州）政务云免费提供；无法提供或有偿提供的另行申请
- 已含实施费的成品软件，该部分不再纳入系统集成费计算基数
- 实施服务费仅适用"行业应用软件+实施服务"情形；操作系统、数据库等不计取
- 软硬一体化设备：按软件授权计费→入本项；按台计费→入硬件设备购置费
- **开源软件不计购置费，应计实施服务费**
- 示例：中间件 1 套 45 万 + 数据库 2 套 15 万（均含实施费）= 75 万元

#### 3.1.2 定制软件开发费（5.2.3，公式链见 [3.2](#32-定制软件开发费功能点法详解)）

**公式**：SDC = 软件开发工作量（AE）× 人月费用单价（F）

- 排除项：数据迁移、第三方测评、质保期后运维
- 包含：定制软件系统内自身集成实施 + 本级地区（如省本级）推广实施；**不含**与其他系统的集成实施及下级地区推广
- 采用专家经验法/功能点法测算工作量时**默认包含第 1 年运维费用**
- 定制软件之间的接口开发费已计的，接口不再计集成实施费
- 政务项目：应交付全部源代码+开发环境，著作权登记为项目单位；其他行业按合同约定，无约定归受托人

#### 3.1.3 数据建设费（5.2.4）

| 子项 | 公式 | 要点 |
|---|---|---|
| 数据资源购置费 | ∑(数据量市场单价×数量) | 文献/地图/遥感/AI 训练/风控/管线等数据；所有权或使用权归购买方；须挂载政务数据共享平台 |
| 数据服务购置费 | ∑(市场单价×数量) | 查询服务按次数或年限；产品服务（OCR/人脸/语音等）按次数、调用量 |
| 数据资源建库费 | 人月工作量×人月单价 | 建库人员 1.5 万/人月 |
| 数据加工费 | 工作量×人月单价 | 全生命周期数据管理活动；测试梳理 1.2 万/人月 |
| 模型搭建费 | 市场单价×数量×调整系数(0.1-1.0) 或 工作量×人月单价 | BIM/3D/GIS/VR 等；应用系统内模型并入开发费，确需单列须举证 |

未纳入的数据建设费用参考 T/SCSDSJFZYJH 027-2025。

#### 3.1.4 系统集成费（5.2.5 + 附录 F）

**公式**：系统集成费 = 集成对象总费用 × 系统集成费率 × 调整系数

- **集成对象总费用 = 相关设备购置费 + 成品软件购置费 + 定制开发软件费**（不含数据服务、标准规范编制费等）
- 费率上限：基础环境 ≤3%、硬件 ≤5%、软件 ≤8%
- 调整系数 0.6-1.2（依据项目性质/规模/复杂度/地域/周期/服务能力/安全/保密/质量）；**一般 1.0，涉密项目 1.1-1.2**
- 软件系统间接口开发费不计集成实施费；独立定制开发软件不计取
- 示例：硬件 80 万×5%×1.0 + (成品软件 30+开发 100)×8%×1.0 = 14.4 万元

#### 3.1.5 标准规范编制费（5.2.6）

**公式**：编制工作量 × 人月费用单价。宜引用/修订现行标准；建设单位自行组织编制的不计入。

#### 3.1.6 系统迁移费（5.2.7 + 附录 G）

**公式**：迁移工作量 × 人月费用单价

**附录 G 表 G.1 迁移难度五级对照**：

| 难度依据 | 1 级 | 2 级 | 3 级 | 4 级 | 5 级 |
|---|---|---|---|---|---|
| 业务规模（个） | ≤5 | 6-20 | 21-40 | 41-120 | >120 |
| 业务数据总量（TB） | ≤1 | 1-10 | 10-30 | 30-100 | >100 |
| 系统关联接口数量（个） | ≤20 | 21-50 | 51-100 | 101-200 | >200 |
| 业务允许中断时间（小时） | ≤48 | ≤8 | ≤8 | ≤1 | ≈0 |
| 特殊设备 | 不包括 | 不包括 | 包括 | 包括 | 包括 |
| 灾备等级 | 1、2 级 | 3 级 | 4 级 | 5、6 级 | 5、6 级 |
| 数据库改变 | 直接迁移 | 直接迁移 | 直接迁移 | 同构数据库改造 | 异构数据库迁移、改造 |
| **工作量预估** | ≤3.3 人月 | ≤6.6 人月 | ≤13 人月 | ≤26 人月 | 一事一议 |

#### 3.1.7 其他与项目建设有关的费用（5.2.8 + 附录 H）

| 费用项 | 计取方法 | 要点 |
|---|---|---|
| 建筑安装工程费 | 直接费+间接费+利润+税金 | 按国家/省工程计价标准；政务项目原则上不新建机房（涉密除外） |
| 硬件设备购置费 | ∑(设备市场单价×数量) | 六类设备范围（采集/传输/存储/计算/展示/安全）；与政务系统非必须关联的电脑打印机不入范围；**含≥3 年质保** |
| 内场适应性改造费 | 按市场清单计取 | 运营中心/指挥大厅/展厅等设备安装及改造 |
| 外场设备安装费 | 按市场清单计取 | 含安全生产费；不与系统集成实施费重复计取 |

| 建设期网络租赁费 | ∑(市场单价×数量×租赁期) | 原则上≤1 年；建成后转运维费 |

### 3.2 定制软件开发费·功能点法详解

#### 3.2.1 公式链（5.2.3.2/5.2.3.4）

```
定制软件开发费 SDC = 调整后工作量 AE（人时） ÷ 人月折算系数 HM × 人月费用单价 F
AE = 未调整工作量 UE × 软件开发项目工作量调整因子 SWF
UE = 基准生产率 PDR（人时/功能点） × 调整后功能点数 S
S  = 经重用程度调整后的功能点数 US × 规模变更因子 CF
US = 未调整功能点数 UFP × 重用程度
SWF = ST（应用类型） × NF（非功能性特征） × SL（开发平台，若涉及） × DT（开发团队背景，若涉及）
NF  =（性能效率 + 兼容性 + 可靠性 + 可移植性）× 0.025 + 1   ← 四项各取 +1/-1
```

- HM = 174 人时/人月；F 见表 D.1（开发人员 2.0 万/人月）
- **可研/初设阶段 SWF 仅考虑 ST、NF**；项目交付后及运维阶段才考虑 SL、DT

#### 3.2.2 规模计数三法（按阶段选用）

| 方法 | 公式 | 适用阶段 |
|---|---|---|
| 预估功能点计数（RFP） | UFP = 35×ILF + 15×EIF | 可研/估算阶段；**仅适用新开发项目，升级改造不适用**（3.9） |
| 估算功能点计数（QFP，快速功能点） | UFP = 10×ILF + 7×EIF + 4×EI + 5×EO + 4×EQ | 初设/概算、预算编制阶段 |

计数项定义：数据功能 = ILF（内部逻辑文件）+ EIF（外部接口文件）；事务功能 = EI（外部输入）+ EO（外部输出）+ EQ（外部查询）。

## 4. 信息化服务（购买服务/租赁）项目

依据：财政部令 102 号、川办发〔2025〕23 号、川财规〔2021〕15 号。**服务期不应超过三年**，且须经济性论证（购买服务整体效益明显优于自建）。按服务项或服务量付费。

### 4.1 成品软件租赁服务费（L.2）

- 整体使用模式：**购置费 ÷ 分摊年限 × 服务期**
  - 服务期满软件归属购买主体：分摊年限按 3 年或合同约定服务年数
  - 不归属：按折旧年限（一般不低于 6 年）
- 按次使用模式（电子印章、人脸识别等基础能力调用）：**服务期内实际使用次数 × 单价**，据实结算

### 4.2 信息化设备租赁服务费（L.3）

**公式**：硬件设备购置费 ÷ 分摊年限 × 服务期 + ∑(运维费用)

- 原则上服务期满不形成固定资产；分摊年限按设备折旧年限（计算机设备类**不低于 6 年**；服务期>折旧年限不建议此法）
- 免费运维期内不计运维费；服务期运维按第 7 章及附录 K
- 特殊情况服务期满设备归属购买主体的：按 3 年或合同约定年数分摊
- 算例（6 台×10 万服务器、租 3 年、1 年免费运维、折旧 6 年）：年费 = 60/6 + 免费期后 60×5%（硬件维保）→ 三年 10/13/13 万，均摊 12 万/年

### 4.3 定制开发软件租赁服务费（L.4）

**公式**：∑(定制软件开发费 ÷ 服务期 × 经济性系数)

- 按 3 年或合同约定服务年数平均分摊；可按月/季/年付费
- 经济性系数 = 实际服务指标完成情况 ÷ 合同约定服务指标，**不超过 1.0**
- 服务期间形成的数据资源归购买主体
- 其他成果（设计文件/源代码/测试文档/接口/超管权限等）及知识产权：
  - 归属购买主体 → 系数 **1.0**
  - 归属承接主体 → **0.5-0.8**（表 L.2）：

| 软件类别 | 说明 | 经济性系数 |
|---|---|---|
| 业务处理、信息管理系统软件 | OA/财务/人事/资产/审批/报表等，需求边界清晰 | 0.5 |
| 基于统一平台业务软件 | 以统一支撑平台为基础，可加权确定工作量 | 0.6 |
| 基于新技术的软件 | 大数据、云计算、区块链、物联网等 | 0.8 |

- 算例：600 万开发费、3 年、新技术类（系数 0.8）→ 每年 600/3×0.8 = **160 万元**

### 4.4 其他租赁服务费（L.5)

数据资源、云资源、网络链路等租赁，按 5.2.4、附录 H H.6/H.7 计取后汇总。

## 5. 运维项目

### 5.1 总则（第 7 章）

- 运维项目费用 = 免费运维期（**自竣工验收合格之日起不少于 1 年**）过后的运维费用
- 构成：基础设施维保费、硬件设备维保费、软件运维费、等保测评/密码测评及安全服务费、其他运维服务费
- 四项必须运维活动：例行操作（监控/预防性检查/常规作业）、响应支持（事件/请求/应急）、优化改善（适应性/增强性/预防性）、调研评估
- 测算路径：**上限**按《四川省省级政务信息化项目运行维护费支出预算标准》IT 资产系数法（附录 J）；**明细**按 GB/T 28827.7 工作量法（附录 K）
- 涉密运维：按需（按次）/阶段（固定周期）/驻场运维，采用工作量法测算

### 5.3 工作量法（附录 K）

按 GB/T 28827.7 成本度量：将运维服务分解为**例行操作/响应支持/优化改善/调研评估**四类活动，逐项明确服务模式（集中监控/远程+现场）、服务时间（7×24、5×8）、服务级别（响应/到场/解决时限）、事务数量、服务频次（次/日、次/月、次/季、次/年）、单个事务处理时间，汇总年工作量（分钟）并折算人月：

```
年工作量（人月） = 年工作量（分钟） ÷ (21.75 天 × 8 小时 × 60 分钟)
```

示例（9 台服务器运维，附录 K 表 K.1）：监控 0.6293 + 预防性检查 0.6750 + 常规作业 0.0310 + 事件响应 0.0517 + 服务请求响应 0.2069 + 适应性改进 0.0690 + 增强性改进 0.0920 + 预防性改进 0.0920 + 调研评估 0.0920 ≈ **1.94 人月/年**。

## 6. 通用商务约束与计算方法

### 6.1 询价与定价证据（贯穿全文）

| 采购对象 | 要求 |
|---|---|
| 成品软件/硬件/云资源/数据资源/数据服务/模型/数据安全评估 | ≥3 家同级别不同品牌厂商（代理商/云商/交易所数据商）询价报价单，有效期≥3 个月；或近 1 年内同类中标（合同）价及证明材料，或目录指导价 |
| 单一来源 | 特殊行业数据资源/数据服务仅能单一来源购买的，须单独举证说明 |
| 硬件设备 | 购置费应包含不少于 3 年质保，特殊情况须举证 |

报价单须含：品牌/规格/功能性能参数、单价、授权方式（软件）、报价单位（加盖公章）、联系人电话等。

### 6.2 差额定率累进法

分档划分计费基数，各档分别乘对应费率后**加总**（不是全额乘最高档）。例（项目管理费，3000 万）：1000×2% + 2000×1.5% = 50 万。

### 6.3 直线内插法

计费基价在两档之间时线性内插。例（监理费，400 万）：6.5 + (400-200)/(500-200)×(13.2-6.5) = 10.97 万，再乘调整系数。

### 6.4 政务云优先原则

网络、存储、计算、安全等基础性公共性资源及成品软件原则上由省级和市（州）政务云免费提供；无法提供或有偿提供的由项目单位另行申请。政务项目（除涉密）原则上不允许新建数据中心、机房。

### 6.5 知识产权

政务定制开发软件：交付全部源代码+开发环境，著作权登记为项目单位；购买服务形成的数据资源归购买主体（详见 4.3）。
