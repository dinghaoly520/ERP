# 供应商管理板块需求文档

## 智慧水发 · ERP体系下一期智慧招采平台

---

## 1. 文档概述

### 1.1 文档目的

本文档用于明确“智慧水发 · ERP体系下一期智慧招采平台”中供应商管理板块的建设需求，作为后续系统设计、原型设计、开发实施、测试验收和上线运行的重要依据。

供应商管理板块主要围绕供应商注册、供应商入库、供应商信息维护、供应商参与记录沉淀和供应商评价管理等内容进行建设，支撑集团招采业务中供应商资源的统一管理和规范使用。

### 1.2 模块定位

供应商管理板块定位为平台的供应商资源管理中心，主要用于实现供应商从注册申请、资质审核、入库管理、信息维护、参与记录、评价记录到状态管理的全过程管理。

本模块不承担合同履约、结算支付、财务往来等后续 ERP 深化功能。本期供应商评价主要围绕供应商注册资料、投标参与、投标响应、配合情况、异常行为等招采过程数据展开。

---

## 2. 建设目标

供应商管理板块建设目标如下：

1. 实现供应商线上注册  
   支持供应商通过平台自主注册，提交企业基础信息、联系人信息、资质材料等资料。

2. 建立统一供应商库  
   对通过审核的供应商进行统一入库管理，形成集团统一的供应商资源池。

3. 规范供应商准入流程  
   通过线上审核、资料补正、状态流转和操作留痕，实现供应商准入管理规范化。

4. 沉淀供应商参与记录  
   记录供应商参与招投标项目、标书投递、开评标结果等信息，为后续管理和评价提供依据。

5. 建立供应商评价机制  
   支持对供应商投标响应、资料完整性、配合情况、异常行为等进行评价，形成供应商信用参考。

6. 支撑平台招采主流程  
   为公告查看、标书投递、投标系统、结果公示等业务提供供应商身份和数据支撑。

---

## 3. 建设范围

### 3.1 本期建设内容

供应商管理板块本期包含三个一级功能：

1. 供应商注册
2. 供应商库
3. 供应商评价

同时配套建设以下支撑能力：

- 供应商审核
- 供应商信息维护
- 资质材料管理
- 供应商状态管理
- 供应商参与记录
- 消息通知
- 操作日志
- 数据查询与导出

### 3.2 本期不纳入内容

本期暂不建设以下内容：

- 合同履约评价
- 付款信用评价
- 财务往来记录
- 供应商结算管理
- 供应商绩效考核复杂模型
- 外部征信平台深度集成
- 供应商门户移动端独立 App

相关内容可作为后续 ERP 深化建设方向预留。

## 4. 用户角色与权限

### 4.1 供应商用户

供应商用户主要使用注册、资料维护、投标参与和结果查看等功能。

主要权限包括：

- 注册供应商账号
- 填写和维护企业信息
- 上传资质材料
- 查看审核状态
- 接收审核结果通知
- 查看公告
- 下载招标文件
- 提交投标文件
- 查看本人投标记录
- 查看结果公示
- 查看本人评价结果，按权限开放

### 4.2 采购中心员工

采购中心员工负责供应商审核、供应商库维护和供应商评价管理。

主要权限包括：

- 查看供应商注册申请
- 审核供应商资料
- 退回补正供应商资料
- 将供应商纳入供应商库
- 查看供应商参与记录
- 发起或维护供应商评价
- 调整供应商状态
- 查询和导出供应商数据

### 4.3 系统管理员

系统管理员负责系统配置、权限维护和基础数据维护。

主要权限包括：

- 配置供应商分类
- 配置资质类型
- 配置审核流程
- 配置评价指标
- 管理用户账号
- 查看操作日志
- 维护系统参数

### 4.4 领导权限

领导用户主要进行查询和监管。

主要权限包括：

- 查看供应商总体数量
- 查看供应商分类统计
- 查看重点供应商信息
- 查看供应商评价统计
- 查看异常供应商情况
- 查看供应商参与项目情况

## 5. 业务流程设计

### 5.1 供应商注册流程

#### 5.1.1 流程说明

供应商通过统一门户进入注册入口，填写企业信息并提交资质材料。系统对基础信息进行格式校验和重复性校验，提交后进入审核流程。采购中心员工审核通过后，供应商进入供应商库；审核不通过或资料不完整的，可退回供应商补正。

#### 5.1.2 流程步骤

1. 供应商进入统一门户
2. 点击供应商注册
3. 填写企业基础信息
4. 填写联系人信息
5. 上传资质材料
6. 阅读并确认平台承诺或声明
7. 提交注册申请
8. 系统进行基础校验
9. 采购中心员工审核
10. 审核通过，进入供应商库
11. 审核退回，供应商补充修改后重新提交
12. 审核不通过，流程结束并记录原因

#### 5.1.3 状态流转

| 状态 | 说明 |
|---|---|
| 草稿 | 供应商已填写部分信息但未提交 |
| 待审核 | 供应商已提交注册申请，等待审核 |
| 退回补正 | 审核人员认为资料不完整或需修改 |
| 审核通过 | 供应商资料审核通过 |
| 已入库 | 供应商正式进入供应商库 |
| 审核不通过 | 供应商不符合准入要求 |
| 停用 | 供应商因异常或管理需要被暂停使用 |

---

### 5.2 供应商入库管理流程

#### 5.2.1 流程说明

供应商审核通过后自动进入供应商库，系统形成供应商档案。采购中心员工可对供应商进行分类、状态维护、资质查看、参与记录查询和评价记录管理。

#### 5.2.2 流程步骤

1. 注册审核通过
2. 系统生成供应商档案
3. 分配供应商编号
4. 进入供应商库
5. 采购中心员工维护分类和状态
6. 后续参与投标时自动形成参与记录
7. 评价结果回写供应商档案

---

### 5.3 供应商信息变更流程

#### 5.3.1 流程说明

供应商入库后，如企业信息、联系人、资质材料等发生变化，可提交信息变更申请。涉及关键字段的变更需经采购中心审核后生效。

#### 5.3.2 流程步骤

1. 供应商登录平台
2. 进入企业信息维护
3. 修改相关信息
4. 上传变更证明材料
5. 提交变更申请
6. 采购中心员工审核
7. 审核通过后更新供应商档案
8. 审核不通过则退回修改

#### 5.3.3 关键字段变更

以下字段建议纳入审核后生效：

- 企业名称
- 统一社会信用代码
- 法定代表人
- 营业执照
- 资质证书
- 经营范围
- 银行账户信息，如本期需要维护
- 授权联系人

---

### 5.4 供应商评价流程

#### 5.4.1 流程说明

供应商评价主要基于招采过程中的参与情况、投标文件响应情况、资料完整性、配合程度和异常行为进行记录。本期评价不涉及合同履约、结算付款和财务表现。

#### 5.4.2 流程步骤

1. 供应商参与采购项目
2. 系统自动记录参与项目情况
3. 开评标结束后形成项目参与记录
4. 采购中心员工根据项目情况发起评价
5. 填写评价指标和评价意见
6. 系统保存评价结果
7. 评价结果归入供应商档案
8. 领导或采购中心员工可查看评价统计

#### 5.4.3 评价触发方式

| 触发方式 | 说明 |
|---|---|
| 项目结束后评价 | 结果公示后，由采购中心员工对参与供应商进行评价 |
| 异常事件评价 | 对投标文件异常、资料虚假、无故撤标等情况进行专项记录 |

## 6. 功能需求

## 6.1 供应商注册

### 6.1.1 功能说明

供应商注册用于支持外部供应商自主申请成为平台供应商。供应商完成信息填报和材料上传后，提交采购中心审核。

### 6.1.2 功能清单

| 功能项 | 功能说明 |
|---|---|
| 注册入口 | 供应商可通过统一门户进入注册页面 |
| 账号创建 | 支持手机号、邮箱或统一账号方式注册 |
| 企业信息填报 | 填写企业名称、统一社会信用代码、企业类型等信息 |
| 联系人信息填报 | 填写联系人、联系方式、邮箱等信息 |
| 资质材料上传 | 上传营业执照、资质证书、授权文件等材料 |
| 信息暂存 | 支持未提交前保存草稿 |
| 信息校验 | 对必填项、格式、重复企业进行校验 |
| 注册提交 | 提交后进入待审核状态 |
| 审核状态查询 | 供应商可查看当前审核进度 |
| 退回补正 | 供应商可根据审核意见修改后重新提交 |
| 注册结果通知 | 通过站内消息、短信或邮件通知审核结果 |

### 6.1.3 主要字段

| 字段名称 | 是否必填 | 说明 |
|---|---|---|
| 企业名称 | 是 | 供应商工商登记名称 |
| 统一社会信用代码 | 是 | 用于唯一识别供应商 |
| 企业类型 | 是 | 如国有企业、民营企业、外资企业等 |
| 法定代表人 | 是 | 企业法定代表人姓名 |
| 注册地址 | 是 | 企业注册地址 |
| 经营范围 | 是 | 企业经营范围 |
| 联系人姓名 | 是 | 平台业务联系人 |
| 联系人手机号 | 是 | 用于通知和登录验证 |
| 联系人邮箱 | 否 | 用于接收系统邮件 |
| 营业执照 | 是 | 上传附件 |
| 资质证书 | 否 | 按供应商类别要求上传 |
| 授权委托书 | 否 | 如非法人操作则需上传 |
| 注册声明确认 | 是 | 供应商确认信息真实有效 |

### 6.1.4 业务规则

1. 统一社会信用代码不得重复注册。
2. 企业名称与统一社会信用代码应保持唯一对应关系。
3. 必填资料未填写完整时，不允许提交审核。
4. 附件格式应支持 PDF、Word、图片等常用格式。
5. 单个附件大小应设置上限，具体由系统管理员配置。
6. 审核退回后，供应商可修改资料并重新提交。
7. 审核不通过后，系统应记录不通过原因。
8. 注册申请和审核操作均应留痕。

---

## 6.2 供应商库

### 6.2.1 功能说明

供应商库用于统一管理已注册、已审核、已入库的供应商资源，形成供应商主数据档案，为招采项目、投标系统、评价管理和数据分析提供基础支撑。

### 6.2.2 功能清单

| 功能项 | 功能说明 |
|---|---|
| 供应商列表 | 展示供应商基础信息、状态、分类、入库时间等 |
| 供应商详情 | 查看企业信息、联系人、资质材料、参与记录、评价记录 |
| 供应商审核 | 对注册申请和信息变更申请进行审核 |
| 供应商分类 | 按行业、业务类型、采购品类等进行分类 |
| 供应商状态管理 | 支持正常、停用、异常、黑名单等状态维护 |
| 资质材料管理 | 查看、维护和更新供应商资质材料 |
| 参与记录 | 记录供应商参与采购项目和投标情况 |
| 信息变更审核 | 对供应商提交的关键信息变更进行审核 |
| 数据查询 | 支持按名称、信用代码、分类、状态等条件查询 |
| 数据导出 | 按权限导出供应商基础信息和统计数据 |
| 操作日志 | 记录供应商资料变更、审核、状态调整等操作 |

### 6.2.3 供应商详情页内容

供应商详情页建议包括以下内容：

1. 基础信息
2. 联系人信息
3. 资质材料
4. 注册审核记录
5. 信息变更记录
6. 参与项目记录
7. 标书投递记录
8. 评价记录
9. 异常记录
10. 操作日志

### 6.2.4 供应商状态

| 状态 | 说明 |
|---|---|
| 待审核 | 已提交注册申请但未审核 |
| 已入库 | 审核通过并可正常参与业务 |
| 退回补正 | 资料需修改补充 |
| 审核不通过 | 不符合准入要求 |
| 正常 | 当前可正常参与投标 |
| 停用 | 暂停其参与平台业务 |
| 异常 | 存在资料异常、行为异常等情况 |
| 黑名单 | 严重违规，不允许参与相关业务 |
| 注销 | 供应商申请或平台管理需要注销 |

### 6.2.5 业务规则

1. 供应商入库后方可参与标书投递。
2. 停用、黑名单状态的供应商不得参与新项目投标。
3. 供应商关键资料变更需审核后生效。
4. 供应商资质材料应保留历史版本。
5. 供应商参与项目后，系统应自动沉淀参与记录。
6. 状态调整必须填写原因，并保留操作记录。
7. 黑名单操作应具备较高权限，原则上仅采购中心负责人或系统授权人员可操作。
8. 供应商信息应按角色控制查看范围，避免敏感信息泄露。

## 6.3 供应商评价

### 6.3.1 功能说明

供应商评价用于记录供应商在招采活动中的表现，形成供应商信用参考，为后续采购管理、供应商选择和风险识别提供依据。

### 6.3.2 评价范围

本期供应商评价主要包括：

- 注册资料完整性
- 资质材料真实性和有效性
- 投标文件响应情况
- 投标文件完整性
- 投标过程配合情况
- 是否存在异常投标行为
- 是否存在无故撤回、逾期提交、资料不一致等问题

本期不包括：

- 合同履约评价
- 到货验收评价
- 售后服务评价
- 付款结算评价
- 财务信用评价

### 6.3.3 功能清单

| 功能项 | 功能说明 |
|---|---|
| 评价发起 | 采购中心员工可基于项目发起供应商评价 |
| 评价指标配置 | 系统管理员可配置评价维度和分值 |
| 评价填写 | 填写评分、评价意见、异常说明等 |
| 评价提交 | 提交后形成正式评价记录 |
| 评价查询 | 按供应商、项目、时间、评价等级查询 |
| 评价统计 | 统计供应商评价等级、评价次数、异常次数 |
| 异常记录 | 对严重异常行为进行专项记录 |
| 评价归档 | 评价结果归入供应商档案 |
| 评价权限控制 | 供应商是否可查看评价结果由系统配置决定 |

### 6.3.4 建议评价指标

| 评价维度 | 评价内容 | 建议权重 |
|---|---|---|
| 资料完整性 | 注册资料、资质文件、投标材料是否完整 | 20% |
| 文件响应情况 | 投标文件是否响应招标文件要求 | 30% |
| 参与配合情况 | 是否按时提交材料、配合开评标工作 | 20% |
| 规范合规情况 | 是否存在异常、虚假、违规行为 | 20% |
| 综合评价 | 采购中心员工综合意见 | 10% |

评价分值可采用百分制，也可采用等级制。

### 6.3.5 评价等级

| 等级 | 分值范围 | 说明 |
|---|---|---|
| A | 90分及以上 | 表现优秀 |
| B | 80—89分 | 表现良好 |
| C | 60—79分 | 表现一般 |
| D | 60分以下 | 表现较差，需重点关注 |

### 6.3.6 异常行为记录

系统应支持记录供应商异常行为，包括但不限于：

- 提交虚假材料
- 投标文件严重缺项
- 未按要求提交文件
- 无故放弃投标
- 投标文件内容异常一致
- 存在疑似围标串标线索
- 联系方式失效且无法联系
- 违反平台管理规则

异常行为应支持上传附件、填写说明、记录处理结果。

## 7. 数据需求

### 7.1 核心数据对象

供应商管理板块涉及以下核心数据对象：

| 数据对象 | 说明 |
|---|---|
| 供应商主档案 | 供应商基础信息和状态信息 |
| 供应商联系人 | 企业联系人和授权联系人 |
| 供应商资质材料 | 营业执照、资质证书、授权文件等 |
| 注册审核记录 | 注册申请和审核结果 |
| 信息变更记录 | 供应商信息修改历史 |
| 参与项目记录 | 供应商参与采购项目情况 |
| 标书投递记录 | 供应商投递标书情况 |
| 供应商评价记录 | 供应商评价分数、等级和意见 |
| 异常行为记录 | 供应商异常事项记录 |
| 操作日志 | 供应商相关操作记录 |

### 7.2 数据关联关系

供应商数据应与以下模块形成关联：

| 关联模块 | 关联内容 |
|---|---|
| 统一门户 | 供应商注册入口、公告查看 |
| 开评标管理 | 标书投递、投标系统、结果公示 |
| 采购管理 | 项目管理、投标文件分析、资料归档 |
| 数据库与数据分析 | 供应商统计、参与记录、评价分析 |
| AI辅助应用 | 投标文件分析、异常提示、知识库问答 |
| 权限体系 | 供应商账号、角色、访问权限 |

## 10. 权限控制需求

### 10.1 权限控制原则

1. 供应商只能查看和维护本企业信息。
2. 采购中心员工可查看供应商库和审核供应商信息。
3. 系统管理员可维护基础配置，但不应随意修改业务评价结果。
4. 领导用户以查询和监管为主，不直接修改供应商业务数据。
5. 黑名单、停用等高风险操作应设置较高权限。
6. 所有关键操作应留痕。

### 10.2 权限矩阵

| 功能 | 供应商 | 采购中心员工 | 系统管理员 | 领导 |
|---|---:|---:|---:|---:|
| 供应商注册 | 可操作 | 可查看 | 可配置 | 可查看统计 |
| 注册审核 | 不可操作 | 可操作 | 可配置流程 | 可查看 |
| 企业信息维护 | 仅本企业 | 可查看/审核 | 可配置 | 可查看 |
| 供应商库查询 | 仅本企业 | 可查询 | 可查询 | 可查询 |
| 供应商状态调整 | 不可操作 | 可操作 | 可操作 | 可查看 |
| 供应商评价 | 查看权限可配置 | 可操作 | 可配置指标 | 可查看 |
| 异常记录 | 查看权限可配置 | 可操作 | 可查看 | 可查看 |
| 数据导出 | 不可操作 | 按权限导出 | 按权限导出 | 按权限导出 |
| 操作日志 | 不可查看 | 可查看部分 | 可查看 | 可查看统计 |

## 11. 与其他模块的衔接

### 11.1 与统一门户衔接

- 统一门户提供供应商注册入口。
- 供应商可通过门户查看公告和政策法规。
- 注册成功后可进入供应商相关功能。

### 11.2 与开评标管理衔接

- 已入库且状态正常的供应商可参与标书投递。
- 投标系统记录供应商投标行为。
- 结果公示与供应商参与记录关联。

### 11.3 与采购管理衔接

- 供应商参与项目记录归入采购项目档案。
- 投标文件分析结果可关联供应商档案。
- 项目归档时同步沉淀供应商参与信息。

### 11.4 与 AI 辅助应用衔接

- AI 可辅助分析供应商投标文件中的报价、资质、业绩和响应情况。
- AI 可对供应商资料完整性、资质有效期、异常记录进行提示。
- AI 输出仅作为辅助参考，不作为最终评价依据。

### 11.5 与电子商城衔接

如果供应商同时作为商城商家，应支持供应商身份与商家身份的关联，但权限应区分。

## 12. 非功能需求

### 12.1 易用性要求

1. 注册页面应分步骤填写，降低供应商填报难度。
2. 必填项、附件要求、格式要求应有明确提示。
3. 审核退回意见应清晰展示，便于供应商修改。
4. 供应商库列表应支持筛选、排序和导出。

### 12.2 安全性要求

1. 供应商资料应按权限隔离。
2. 敏感附件应进行访问控制。
3. 关键操作需记录操作人、时间、内容和结果。
4. 供应商账号应支持密码策略和登录安全校验。

### 12.3 可扩展性要求

1. 供应商分类应支持后台配置。
2. 资质类型应支持后台配置。
3. 评价指标应支持后台配置。
4. 状态规则应支持后续扩展。
5. 预留与后续合同、履约、结算模块的数据关联能力。

### 12.4 性能要求

1. 供应商列表查询应支持分页加载。
2. 大批量供应商数据应支持条件检索。
3. 附件上传和下载应保证稳定。
4. 常用统计报表应在合理时间内返回结果。

## 13. 验收标准

### 13.1 供应商注册验收标准

1. 供应商可通过门户完成注册申请。
2. 系统可校验必填项和统一社会信用代码重复。
3. 供应商可上传资质材料。
4. 提交后状态变更为待审核。
5. 审核结果可通知供应商。
6. 审核退回后供应商可修改并重新提交。

### 13.2 供应商库验收标准

1. 审核通过的供应商可自动进入供应商库。
2. 采购中心员工可查询、查看和维护供应商档案。
3. 系统可记录供应商参与项目情况。
4. 供应商状态可按权限调整。
5. 关键操作均有日志记录。
6. 可按条件查询和导出供应商数据。

### 13.3 供应商评价验收标准

1. 采购中心员工可对供应商发起评价。
2. 系统支持配置评价指标。
3. 评价结果可归入供应商档案。
4. 可按供应商、项目、评价等级查询评价记录。
5. 异常行为可单独记录并留痕。
6. 评价数据可用于统计分析。

## 14. 后续扩展建议

本期供应商管理以注册、入库和招采过程评价为重点。后续可根据 ERP 深化建设逐步扩展以下能力：

1. 供应商履约评价
2. 合同执行评价
3. 到货验收评价
4. 售后服务评价
5. 付款及结算信用记录
6. 外部信用数据接入
7. 供应商分级分类模型
8. 供应商风险预警模型
9. 供应商年度综合评价
10. 与合同、履约、财务系统深度联动

---

## 15. 总结

供应商管理板块是智慧招采平台的重要基础模块。本期建设应重点围绕“注册准入、统一入库、参与记录、评价管理”四个方面展开，既满足当前招采业务落地需要，又避免过度扩展至合同履约和财务结算领域。

通过本模块建设，平台可形成统一供应商资源池，支撑供应商线上注册、规范审核、集中管理、过程评价和数据沉淀，为后续招采管理优化、供应商信用管理以及 ERP 体系深化建设提供基础支撑。
